# Alice Speaker (прототип)

Эксперимент: блок «Колонка с Алисой», который отвечает **настоящей** Алисой через неофициальный веб-протокол
alice.yandex.ru (`wss://uniproxy.alice.ya.ru/uni.ws`). Отдельный мод, не зависит от Mob Talk. Только для себя:
протокол недокументирован и может сломаться в любой момент.

## Как пользоваться

- Скрафтить колонку: нотный блок + осколок аметиста (или вкладка «Функциональные блоки»).
- Встать рядом (до 6 блоков) или навести прицел и **держать B**: говорить, отпустить (максимум 15 секунд).
- Или написать в чат `/alice включи свет`.
- Ответ Алисы появляется в чате, её голос звучит из блока. Сломать блок — голос замолкает.

## Вход в Яндекс

Мод берёт сессию не из конфига, а отсюда (в git, логи и JAR это не попадает):

- `%USERPROFILE%\.alice-speaker\sync.json` — первое исходящее сообщение сайта (`SynchronizeState`) из F12 → Network → WS → `uni.ws` → Messages, правой кнопкой «Copy message». Вход Яндекса едет внутри него;
- `%USERPROFILE%\.alice-speaker\cookies.txt` — строка заголовка `Cookie` с alice.yandex.ru (одной строкой);
- `%USERPROFILE%\.alice-speaker\auth_token.txt` — `auth_token` из первого сообщения `SynchronizeState` сайта (необязательно);
- или переменные окружения `YA_COOKIE` / `YA_AUTH`.

## Яндекс Музыка

Веб-Алиса сама музыку не включает (даже с входом), поэтому «Алиса, включи музыку …» мод выполняет сам через
неофициальный API Яндекс Музыки и играет трек из колонки: «включи музыку группы Кино», «включи мою волну»,
«следующая», «выключи музыку». Без VPN: из других регионов API отвечает «Unavailable For Legal Reasons».

Токен (нужен для «Моей волны» и полных треков; без Плюса Яндекс может отдавать 30-секундные отрывки):
1. В браузере, где вы вошли в Яндекс, откройте
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
   (это приложение Яндекс Музыки для Android) и разрешите доступ.
2. Адресная строка сменится на `...#access_token=y0_...&token_type=...`. Скопируйте значение после
   `access_token=` до знака `&`.
3. Сохраните его одной строкой в `%USERPROFILE%\.alice-speaker\music_token.txt`. Токен никому не отправляйте.

## Самотест

`powershell -ExecutionPolicy Bypass -File alice-prototype\scripts\run-selftest.ps1` (VPN выключен): одноразовая копия
экземпляра `alice-speaker-test`, новый мир, вопрос текстом, ответ Алисы её же голосом обратно как голосовой ввод,
«включи музыку», поломка колонки посреди ответа. Отчёт и снимки: `%LOCALAPPDATA%\AliceSpeaker\selftest\<копия>\`.

## Диагностика

`logs/alicespeaker-protocol.log` в папке игры: имена директив Алисы и начало их содержимого (без cookies).

## Сборка

`gradlew build` в этой папке → `build/libs/alicespeaker-0.1.0.jar`. Нужны Fabric API и Minecraft 1.21.1.
