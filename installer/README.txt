Mob Talk: установка для игрока
================================

Нужно: лицензионный Minecraft Java (аккаунт Microsoft), Windows 10/11 или macOS 12+, интернет.
Установщик ставит Prism Launcher (бесплатный лаунчер Minecraft) и нашу сборку, сервер уже будет в списке.

Windows
  1. Распакуйте архив (правый щелчок -> Извлечь все).
  2. Дважды щёлкните install-windows.bat. Если Windows покажет «Система Windows защитила ваш компьютер»,
     нажмите «Подробнее» -> «Выполнить в любом случае».
  3. Откроется Prism и окно импорта сборки: нажмите OK.

macOS
  1. Дважды щёлкните архив в Загрузках, он распакуется.
  2. Дважды щёлкните install-macos.command. Если macOS не даёт открыть («не удалось проверить разработчика»):
     Системные настройки -> Конфиденциальность и безопасность -> внизу «Всё равно открыть».
     Или откройте Терминал и выполните: bash ~/Downloads/mob-talk-installer/install-macos.command
  3. Откроется Prism и окно импорта сборки: нажмите OK.

Дальше в Prism
  - Справа вверху: Аккаунты -> Управление аккаунтами -> Добавить Microsoft, войдите своим аккаунтом.
  - Выберите сборку Mob Talk -> Запустить. Если Prism предложит скачать Java, согласитесь.
  - Сетевая игра -> сервер Mob Talk уже в списке. Напишите Дмитрию свой ник: без него сервер не пустит.
  - Микрофон: при первом разговоре разрешите Java доступ к микрофону.

Клавиши
  V (зажать) — говорить с жителем или мобом, на которого смотрите; F7 — настройки Mob Talk;
  G — подарить предмет из руки; B — сделки; R — помолиться у Божественного блока.
  Голосовой чат с игроками (Simple Voice Chat): зажмите Caps Lock; его настройки — клавиша Y.
  Карта (JourneyMap): J.
