# Серафим учится уворачиваться

Обучение с подкреплением для босса «Шестикрылый серафим». Сеть смотрит на оружие игрока (лук, арбалет, трезубец,
снежки, зелья), на натяжение тетивы и куда он целится, на снаряды в воздухе и решает, куда подрулить, на какой высоте
висеть и когда сделать «рывок крыльями» (1 блок за тик 5 тиков, отдых 2,5 с).

| Файл | Что делает |
|---|---|
| `sim.py` | Тренажёр: арена с физикой 1.21.1 (полёт Серафима как в `SeraphEntity`, снаряды как в ванили), сотни арен сразу на numpy |
| `train.py` | Обучение PPO (Stable-Baselines3) |
| `evaluate.py` | Доля попаданий без сети и с сетью по оружию и меткости |
| `render.py` | Видео «вид из-за спины игрока»: слева без сети, справа с сетью |
| `export.py` | Веса для мода (`seraph_dodge.bin`, читает `boss/ai/DodgeNet` без библиотек) и ONNX для проверки |
| `baseline.py` | Доля попаданий без сети |

```
pip install -r requirements.txt
python train.py --steps 15000000 --out runs/v2      # ~45 мин на 4 ядрах CPU; видеокарта не нужна
python evaluate.py runs/v2/seraph_dodge.zip
python export.py runs/v2/seraph_dodge.zip ../../src/main/resources/assets/divineblock/ai/seraph_dodge
python render.py runs/v2/seraph_dodge.zip seraph-bow.mp4 --weapon bow
```

Все постоянные (скорости, рывок, круг 12 блоков, порядок признаков) повторены в `boss/ai/SeraphDodge.java`.
Меняете одну сторону — меняйте другую и переобучайте. `DodgeNetTest` сверяет Java-сеть с Python по
`src/test/resources/seraph_dodge_check.txt`; после нового обучения пересоздайте этот файл (см. историю коммита).

Результат v2 (тренажёр, доля попаданий без сети → с сетью при умении 100 % / 70 %):
лук 99 % → 52 % / 61 %, арбалет 99 % → 41 % / 52 %, трезубец 99 % → 0 % / 31 %, снежки 95 % → 15 % / 17 %.
