# Рабочие правила Божественного блока

Отдельный от Mob Talk фановый Fabric-мод для Minecraft 1.21.1 — одиночка и выделенный сервер (docs/multiplayer.md), GPL-3.0.
Код OpenRouter/Jev/ключей перенесён из Mob Talk (тот же автор и лицензия); зависимости от Mob Talk нет, связь с его
веб-админкой — только JSON через entrypoint `mobtalk-admin`.

- Каталог деяний фиксирован (`Miracle`), LLM и Jev выбирают только из него; параметры проверяет код.
- Решения объяснимы: никаких скрытых бросков в выборе, только названные причины с весами.
- Секреты не попадают в git, логи, конфиг JSON и JAR.
- Не блокируйте игровой поток сетью и диском: Jev и речь — на рабочем потоке, чудеса — на серверном.
- Ответ бога отменяется, если игрок умер или сменил мир; если вышел с сервера — кара ждёт его входа до игрового дня, милость отменяется.
- Личные деяния — только просящему, мировые — всем рядом (`core/MiracleScope`); новое деяние внесите в таблицу docs/punishments.md.
- Новое поле `DivineConfig` — либо в `DivineSettings.SERVER`, либо в `PERSONAL` (тест проверяет).
- Тестируйте на отдельном экземпляре Prism (не на экземплярах и мирах Mob Talk).
- Не заявляйте о проверке в настоящей игре без фактического прогона.
