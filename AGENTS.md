# Рабочие правила Mob Talk

Новая сессия начинает с docs/HANDOFF.md (статус, дорожная карта, хвосты, пути и команды), затем docs/playtest-0.6.0-checklist.md.

Это фановый клиентский Fabric-мод для одиночной игры Minecraft 1.21.1.
Пользователь выбрал самостоятельный JAR; зависимость от Viewer Parrots запрещена.
Речь распознаётся локально; текст и игровой контекст идут в OpenRouter.

- Не меняйте соседний проект minecraft-parrot и его незакоммиченные изменения.
- Секреты не попадают в git, логи, конфиг JSON и JAR.
- Запись микрофона только по удержанию кнопки; максимум 15 секунд.
- Не блокируйте игровой поток сетью, распознаванием, диском или микрофоном.
- Диалог отменяется при смене мира/цели, смерти/выгрузке моба.
- Применяйте минимальные проверки: одна сборка и относящиеся к новому сценарию тесты.
- Не заявляйте о проверке микрофона/настоящей игры без фактического прогона.
