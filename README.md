# Божественный блок

Fabric-мод для Minecraft 1.21.1 (одиночная игра): алтарь своенравного бога на LLM. Игрок молится, бросает дары на алтарь,
а бог взвешивает его дела и решает, помочь, подшутить или покарать. Лицензия GPL-3.0-only.

## Как это устроено

- **Алтарь** `divineblock:altar`: крафт — 3 золотых слитка сверху, кварцевый блок, алмаз, кварцевый блок посередине, 3 обсидиана снизу.
  ПКМ открывает экран молитвы. Дары бросаются на алтарь заранее и сгорают при молитве.
- **Вердикт без кубика** (`core/VerdictBuilder`): каждое решение — список названных причин с весами (праведность, свежие дела,
  подношение, тон молитвы, повторы, нрав бога, прихоть). Сумма даёт склонность (помощь, шутка, кара, знамение) и бюджет силы 0–4.
- **Выбор деяния**: Jev (`~typesafe/jev-latest`, Decisions API OpenRouter) выбирает из каталога (`core/Miracle`, 31 деяние) в
  пределах бюджета; при ошибке или таймауте 1,5 с решают правила (`RuleGodDecider`). Сила Jev обрезается по бюджету и настройкам.
- **Речь бога** (`core/GodSpeech`): чат-модель OpenRouter (или Venice с откатом на OpenRouter) объявляет решение и называет главную
  причину; без сети работает шаблон. «Почему?» у алтаря — бог пересказывает последний вердикт.
- **Только молитва**: Jev решает, обращена ли речь к богу; болтовню у алтаря бог не слышит (без Jev — правила по обращению).
- **Без второго шанса**: бог не переспрашивает и не ждёт; решив, действует сразу (серьёзная кара — с громом и титром «Гнев небес»), а может и осознанно промолчать.
- **Слог**: загадочный, старорусский, с библейскими метафорами и отсылками.
- **Праведность** −100..+100 (`core/Righteousness`): бог сам видит убийства жителей, големов и питомцев, массовый забой, разгром
  деревни, защиту жителей, победы в рейдах, разведение, торговлю и посадки. У каждого дела дневной предел, шкала дрейфует к нулю.
- **Голос**: удерживайте R у алтаря и молитесь вслух (до 15 секунд); речь распознаёт локальный Whisper — тот же помощник, что
  у Mob Talk (`127.0.0.1:63919`), при необходимости он запускается из установленного окружения Mob Talk. Бог отвечает вслух
  глубоким голосом ElevenLabs через OpenRouter (выбор голоса и выключатель в F9); без сети остаются субтитры.
- **Настройки** — F9: нрав, потолок кары, визер, защита блоков, прихоть, задержка, пауза алтаря, Jev, провайдер речи, ключи, отладка.

## Ключи

Ключ OpenRouter ищется так: переменная `OPENROUTER_API_KEY`, файл `config/divineblock-openrouter-token.txt`, ключ, сохранённый
в настройках (DPAPI Windows, `%LOCALAPPDATA%\DivineBlock`), и наконец ключ Mob Talk (только чтение). Ключи не попадают в JSON,
логи и JAR. То же для Venice (`VENICE_API_KEY`).

## Сборка

```
./gradlew build
```

JAR: `build/libs/divineblock-<версия>.jar`. Нужен Fabric API.
