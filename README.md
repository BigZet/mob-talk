# Mob Talk 🗣️

**Поговори с любым мобом в Minecraft голосом.** Наведи прицел на моба, зажми V и скажи что угодно в микрофон — моб ответит своим голосом. Без готовых фраз: у каждого свой характер, память и отношение к тебе.

## Что умеют мобы

- 🧟 **Действуют по разговору.** Нахамил жителю — убежит. Довёл крипера — рванёт по-настоящему. Попросил прирученного волка — пойдёт за тобой или кинется на зомби. А может и отказаться.
- ⚖️ **Трезво оценивают расклад.** Перед ответом моб прикидывает, кто кого: твой меч и броня против его зубов и здоровья, сородичи рядом, сколько раз ты его уже бил. Житель перед алмазным мечом не хорохорится — просит пощады и бежит; стая волков перед голым игроком наглеет.
- 👀 **Очевидцы всё видят.** Ударил, убил, оскорбил или пригрозил одному — остальные в поле зрения запомнили и разлюбили тебя. А после ответа собеседника кто-то из них может и вставить слово: поддержать, съязвить, испугаться — по очереди, не больше трёх голосов подряд.
- 😡 **Ненависть с последствиями.** Довёл отношение до −40 — боец нападёт, как только решит, что сильнее; кто драться не умеет, убегает, а житель зовёт голема.
- 💰 **Торгуют и торгуются — все 82 вида.** У каждого свой товар и своя валюта: корова отдаст молоко за пшеницу, зомби — морковку «от последнего парня» за свинину, эндермен — жемчуг за дёрн. Сбитая цена остаётся навсегда и может падать дальше; у жителя уступка сразу встаёт в окно торговли.
- 🗝️ **Прячут секретные сделки и просят об услугах.** Моб сам придумывает, что ему принести и зачем; принеси — и он откроет то, чего не показывал, или скинет цену.
- 🌱 **Живут своей жизнью.** У каждого вида свои речевые привычки, цель в жизни и тайна, которую выдают только друзьям, а разговор начинается из настроения: ночь, дождь, недавний удар.
- 🧭 **Понимают, где стоят.** Моб знает форму места, а не только список блоков: яма 3×3 глубиной 4 из бедрока без выхода, стеклянная клетка, воронка, где вода тащит к дыре с лавой, дом с открытой дверью на востоке, столб с обрывом вокруг. И кто это построил: «из блоков вокруг тебя 20 поставил игрок за последние 2 минуты — это он тебя замуровал».
- 🧠 **Помнят и замечают.** Видят, что у тебя в руках, во что ты одет, кто бродит рядом. Помнят, как ты их бил, оскорблял или помогал.
- 🐺 **82 вида с характерами.** Гордый волк не признает, что он пёсик, даже в ошейнике. Кролик требует держаться в пяти блоках. Овца уверена, что твой «милый пёсик» её сожрёт.
- 🤬 **Дерзость на выбор:** от «без мата» до «без тормозов».

Minecraft 1.21.1 · Fabric · одиночная игра. Нужен ключ [OpenRouter](https://openrouter.ai): через него работают нейросеть и голоса (платно, по факту использования).

**Как это устроено:** речь распознаётся локально (Whisper), ответ пишет LLM через OpenRouter с учётом личности моба и того, что происходит в мире, а озвучивает ElevenLabs Eleven Flash v2.5 из позиции моба. Всё, что ниже, — установка и подробности.

## Установка с нуля

Нужны Minecraft Java **1.21.1**, Java **21**, Fabric Loader **0.19.5**, Fabric API **0.116.17+1.21.1**, Python **3.12** и PowerShell **7**.

1. Положите `mobtalk-0.5.0.jar` и Fabric API в `mods` своего инстанса.
2. Из папки проекта выполните в PowerShell 7: `./scripts/setup-whisper.ps1 -NoStart`. Скрипт создаёт отдельное окружение `%LOCALAPPDATA%/MobTalk`, устанавливает совместимые библиотеки и скачивает модель. По умолчанию `large-v3`; для лёгкого начала добавьте `-Model small`, для CPU — `-Device cpu`. Остальные модели загружаются из игрового меню.
3. Нажмите в игре **F7 → Общее**, вставьте OpenRouter API-ключ в поле «API-ключ» (кнопка «Вставить» или Ctrl+V) и нажмите «Сохранить ключ». Ключ скрыт звёздочками, шифруется Windows (DPAPI) для вашей учётной записи в `%LOCALAPPDATA%\MobTalk\openrouter-key.dpapi` и не попадает в `mobtalk.json`, JAR или память мира. По-прежнему поддерживаются `OPENROUTER_API_KEY` (важнее ключа из меню) и `config/mobtalk-openrouter-token.txt`.
   Ответы мобов можно получать и через **Venice**: в F7 → «Общее» переключите «Провайдер» на Venice, вставьте ключ Venice в появившийся раздел и укажите модель (по умолчанию `deepseek-v4-1-flash`). **Озвучка** выбирается отдельно в том же разделе: «Провайдер озвучки» OpenRouter (голоса ElevenLabs по ID из каталога видов, модель по умолчанию `elevenlabs/eleven-flash-v2.5`, можно вписать другую, например `elevenlabs/eleven-multilingual-v2`) или Venice: с моделью `tts-elevenlabs-turbo-v2-5` у мобов остаются те же голоса ElevenLabs по ID, что и через OpenRouter, а `tts-kokoro` и другие модели Venice знают только свой каталог, и тогда один голос на всех (например `af_sky`; русских голосов у них нет, так что это акцент). Разделы ключей показываются по тому, какие провайдеры задействованы. Ключ Venice хранится так же: `%LOCALAPPDATA%\MobTalkenice-key.dpapi`, `VENICE_API_KEY` или `config/mobtalk-venice-token.txt`.
4. Запустите одиночный мир, нажмите **F7**, выберите микрофон и откройте его проверку.

Обновление из собранного проекта в Prism: `./scripts/install-prism.ps1 -Instance '1.21.1-fabric-dev'`. Старые JAR сохраняются в `mobtalk-backups`. Для загрузки версии перезапустите Minecraft. Viewer Parrots устанавливается отдельно и не требуется для Mob Talk.

## Управление

- **Прицел на моба + удерживать V** — говорить с тем, кто в прицеле (до 16 блоков, по умолчанию); отпустить — отправить. Если в прицеле никого, говорите с прежним собеседником. В строке HUD видно, кто в прицеле и кто собеседник. Клавиша меняется в настройках управления Minecraft; `/mobtalk clear` снимает выбор.
- **B** или `/mobtalk trade` — ванильное окно торговли с личными сделками выбранного моба: своя цена с зачёркнутой исходной, строки `???` с подсказками о секретных сделках, текущая услуга. У жителя и странствующего торговца B открывает то же окно, что и ПКМ, — их товар только там. Повторное **B** закрывает окно. В заголовке и в строке HUD видно отношение моба к вам.
- **F7**, `/mobtalk` или **Esc → Mob Talk** — настройки.
- `/mobtalk say Текст` — разговор без микрофона.
- `/mobtalk follow`, `/mobtalk flee`, `/mobtalk attack player` — попросить действие; решение принимает моб.
- `/mobtalk attack e1` — попросить атаковать существо с идентификатором из текущего контекста.
- `/mobtalk stop` — отменить действие; `/mobtalk stop_all` — остановить управление всеми последователями.
- `/mobtalk status`, `clear`, `reload`, `mic list` — состояние мода, снятие выбора, перечитывание настроек и устройства.
- `/mobtalk state` — состояние выбранного моба по всем осям (настроение, спокойствие, интерес, доверие) и его последняя мысль.

## Характер и память

У всех 82 ванильных видов отдельные профили и по три архетипа. UUID получает постоянные голос, архетип и индивидуальные особенности. Имя в игре автоматически не меняется. Настоящие профессия жителя, характер панды, возраст, хозяин питомца и агрессия учитываются отдельно.

При первой встрече моб получает **свою историю** прямо внутри первого ответа (отдельного запроса нет): модель придумывает ему имя-прозвище и биографию в три предложения — откуда он, что пережил, что ищет, — и дальше говорит из неё; имя видно в чате с первой же реплики. У первого встреченного жителя деревни рождается и **история деревни** (название, как возникла, чем славится, беда или легенда); соседи в радиусе 160 блоков от колокола или дома первого жителя наследуют её и не выдумывают свою. Истории хранятся в памяти мира.

У каждого вида есть **речевые привычки** (фирменные словечки, что бесит и что смешит), **цель в жизни** (крипер хочет поймать молнию и попасть в красивый дом, житель — колокол на площадь) и **тайна**, которую моб выдаёт только при отношении от 60; чужому лишь намекает. Промпт начинается с этого, а не с торговли: моб не перечисляет товары без вопроса и не говорит как продавец. Разговор стартует из состояния — код описывает модели, цел ли моб, горит ли, мокнет под дождём или сидит под крышей, ночь ли, били ли его недавно и голоден ли игрок.

Моб получает свежие сведения об обеих руках, снаряжении, своём состоянии, времени, погоде, биоме, близких существах и объектах вокруг. Варден воспринимает доступные ему звуки и вибрации.

История по умолчанию — 24 обмена, в меню до 64. На диске до 100 обменов и память до 4000 символов. После каждого ответа модель сообщает только новые факты (до 300 символов) и их **важность** 1–5: 5 — удар, угроза жизни, нарушенное обещание; 4 — сделка, подарок, выполненная просьба; 3 — договорённость; 2 — обычный разговор; 1 — мелочь. События из самой игры получают важность автоматически (удар и убийство на глазах — 5, помощь, покупка и выполненная услуга — 4, открытый секрет и просьба об услуге — 3). У каждого факта и события есть оценка «важность × свежесть» (по образцу Generative Agents: свежесть тает вдвое за неделю реального времени, но не ниже 30 %): в промпте факты идут от важных к мелким, а при переполнении памяти первыми забываются маловажные и старые — удар месячной давности переживёт вчерашнюю болтовню. Факты из сохранений прежних версий получают важность 3; в карточке моба память по-прежнему редактируется как текст, строка на факт.

**Сводки разговоров.** Когда разговор заканчивается — вы отвернулись к другому мобу, сняли прицел или три минуты молчали, — мод одним фоновым дешёвым запросом сжимает его в 2–4 предложения от первого лица моба: о чём говорили, что решили, что обещали, как моб к этому относится. Сводки (до 8 на моба, старые вытесняются) хранятся в памяти мира, и в следующий разговор идут они, а не длинный хвост старых реплик; реплики текущего разговора остаются в промпте как раньше. Запрос не удался — хвост остаётся как был. Фон никогда не задерживает ответ моба.

**Рефлексия.** Раз в несколько реплик (не раньше четвёртой с прошлого раза и только если с тех пор накопилось больше 8 единиц важности, не чаще раза в минуту на моба) моб в фоне думает об игроке: по своей памяти и сводкам формулирует один-два вывода от первого лица — «он всегда платит», «обещает и не приходит», «со мной добр, а соседей бьёт». Выводы хранятся как факты особого вида (важность 4, в карточке помечены `[вывод]`, не больше 6) и попадают в промпт отдельной строкой «Что я понял об этом игроке». Все фоновые запросы — сводки и рефлексия — идут через одну очередь из одного потока на весь мод и используют модель из `backgroundModel` в `mobtalk.json` (пусто — модель диалога) с минимальным размышлением и небольшим `max_tokens`.

Ответ модели приходит потоком: как только готов текст реплики, мод начинает озвучку, не дожидаясь фактов и действия, а звук играет по первым байтам. Если реплика после проверок изменится или будет отклонена, ранняя озвучка отбрасывается. Память: `data/mobtalk/conversations.json` в мире; перед миграцией создаётся `conversations.v1.backup.json`.

Мобы помнят настоящие удары игрока и его снарядов, включая события до знакомства. Урон окружения не обвиняет игрока. Извинения, настоящая помощь, покупки и выполненные услуги постепенно улучшают отношение. Любой удар рвёт дружбу: первый роняет отношение до −80, следующие оставляют моба ниже нуля.

**Очевидцы.** Мобы, которые уже знакомы с вами и видят жертву (до 16 блоков), берут на свой счёт удар (−10) и убийство (−25) другого моба, а в 5 блоках ещё и оскорбление (−5) и угрозу убить (−10) — не чаще раза в пять секунд — и помнят это («Видел, как игрок … убил Марфу (корова)»). Модель видит в оценке обстановки, сколько раз вы били её и сколько раз она видела, как вы обходились с другими.

**Трезвая оценка обстановки.** Перед ответом код считает, кто кого: оружие и броня игрока против тела моба (умеет ли драться, урон, здоровье) и его сородичей в 10 блоках. Вывод — «не выжить», «он сильнее», «силы равны» или «ты сильнее» — попадает в промпт как факт, а модель заполняет поле `assessment` (оценка про себя, не озвучивается) раньше реплики: обречённый не хорохорится, сильный не лебезит. Страх и просьбы о пощаде появляются только при реальной угрозе (вас били, вы враг, вы расправлялись с другими на его глазах, отношение ниже нуля): друг в алмазной броне никого не пугает, а враждебный вид и обречённым остаётся врагом — грозит издали и отступает, но пощады не просит. Творческий режим — всегда «не выжить». Очевидцы не винят вас за монстров и за тех, кто сам на вас напал. Бессмертные боссы (дракон, иссушитель, варден, древний страж) всегда «сильнее».

**Состояние моба.** Кроме отношения у каждого моба есть сиюминутное состояние по четырём осям 0–100: **настроение** (мрачно ↔ радостно), **спокойствие** (тревога ↔ покой), **интерес** к игроку (скука ↔ увлечённость) и **доверие** (настороженность ↔ доверие; в отличие от отношения меняется быстро и само возвращается). У каждой оси есть точка покоя из темперамента особи (спокойствие — из её спокойствия, настроение — из уверенности и общительности, интерес — из любопытства, доверие — из отношения к вам), и отклонение затухает к ней по реальному времени: половина за 10 минут, а после важного — удара, убийства на глазах, угрозы убить, выполненной услуги, настоящей помощи — за 30 минут. Затухание считается при чтении, тиков нет; состояние хранится в памяти мира вместе с остальным.

Что сдвигает оси: удар (спокойствие −35, доверие −35, настроение −25), увиденное убийство (−35/−30/−25) и удар другого (−20/−15/−10), угроза убить (спокойствие −30, доверие −25), оскорбление (настроение −15, доверие −10), извинение (+10 спокойствия и доверия), добрые слова (+10 настроения), настоящая помощь (доверие +20), покупка (+8), выполненная услуга (доверие +25, настроение +20), уступка самого моба (+5 интереса и доверия), сам разговор (интерес +12), а целому и никем не атакованному мобу раз в пять минут возвращается спокойствие — до точки покоя, не выше. Важные события ложатся не меньше чем на полный вес от точки покоя: несколько ласковых слов не смягчают удар, а хандра не обесценивает выполненную услугу. Долгий перерыв без встреч сам возвращает интерес к норме. Все веса — константы в `MobState`.

Модель получает состояние словами, не числами («встревожен», «в духе», «игрок тебе наскучил», «настороже, ждёшь подвоха»), с правилом не называть его вслух, а показывать тоном, темой и поступками, и после каждой реплики возвращает поле `thought` — короткую мысль про себя; она хранится и подставляется в следующий промпт как «твоя последняя мысль» (идея «мыслей» NPC из SkyrimNet). Трезвая оценка обстановки берёт текущее спокойствие, а не только темперамент: только что битый спокойный житель паникует. Последствия: моб со спокойствием ниже 25 или доверием ниже 25 не уступает в торге и не заключает сделок — OFFER исчезает из схемы ответа, а если модель всё же попыталась, ответ отклоняется и моб отказывает словами; моб в духе и с доверием от 65 уступает охотнее (подсказка в промпте); знакомый моб с интересом от 75 сам поворачивается к вам и смотрит, пока вы в 6 блоках (стоит, не ходит). В строке Mob Talk рядом с отношением показывается одно слово состояния — самая сильная ось: красным «встревожен», «не доверяет», «скучает», «мрачен», зелёным «в духе», «доверяет», «увлечён», серым «спокоен»; выключается в F7 → «Общее». `/mobtalk state` печатает в чат все оси словами и числами и последнюю мысль.

**Подозрительность за проступки.** Жители и големы замечают не только удары. Если на глазах у жителя (в 16 блоках, с прямой видимостью) вы откроете в деревне чужой сундук или бочку (−3 к отношению), соберёте урожай с деревенской грядки (−3), сломаете дверь или кровать (−5) или рабочий блок жителя — кафедру, компостер, стол кузнеца и прочие блоки профессий (−8), каждый очевидец запомнит это («Видел, как игрок открыл чужой сундук в деревне»), станет настороженнее и меньше доверять (событие MISCHIEF в состоянии), а хозяин сломанного рабочего блока или кровати заметит и не глядя. Житель-очевидец получает профиль даже если вы с ним ещё не говорили — деревня помнит. В чате видно, кто заметил. Один вид проступка считается не чаще раза в 20 секунд. Ваши собственные постройки не в счёт: блоки, поставленные вами за эту игровую сессию (включая посаженные семена и вторую половину двери или кровати), не считаются чужими; сундуки и грядки вне деревни (дальше двух секций чанка от занятых кроватей, рабочих блоков и колокола) тоже. В промпте проступок — повод для подозрения и колкости, а не для войны: житель припомнит его в разговоре, может отказать в уступке, но не нападёт и не позовёт голема.

**Реплики очевидцев.** После ответа собеседника до двух мобов в 5 блоках от вас (сначала знакомые, потом ближайшие) слышат разговор и могут вставить фразу или промолчать. Думают они параллельно — друг с другом и с голосом собеседника, — а говорят по очереди: голосов подряд не больше трёх, и никто никого не перебивает. Оскорбление, угроза, извинение, бегство или атака собеседника поднимают очевидцев всегда, пустая болтовня — в трети случаев. Очевидец не торгует и не судит ваши слова как сказанные ему, но может убежать или напасть. Число очевидцев задаётся в F7 → «Общее» (0 отключает). Новая запись отменяет ещё не сказанные реплики. Пока моб слушает, думает или говорит, он стоит на месте и смотрит на вас (если не бежит, не дерётся и не в панике).

**Отношения между мобами.** Кроме отношения к вам у каждого знакомого моба (с профилем в памяти мира) есть до 12 связей с другими мобами: оценка −100..100, последняя встреча и теги — **друг** (от +40), **соперник** (от −40), **сородич** (один вид), **семья** (жители и големы одной деревни), **скорбит** (по погибшему, с его именем). Связи возникают из игры, без запросов к модели: мобы, стоящие в 8 блоках друг от друга, сближаются на одно очко за полминуты (соседи по деревне начинают с +10, сородичи с +5; одна близость не поднимает выше +60); мобы, стоящие рядом с вашим собеседником, знакомятся с ним; удар одного моба по другому (ванильные драки: зомби и житель, волк и овца) сразу делает обидчика врагом (−45), а обидчику портит мнение о жертве (−15); гибель моба на глазах знакомого оставляет у очевидца скорбь по имени на три игровых дня — скорбят по тем, с кем ладили, и по всем, у кого есть своя история. Связь, в которой мобы не встречаются, тает наполовину за 6 часов реального времени; враги не мирятся, стоя рядом, — только со временем. Лишняя тринадцатая связь вытесняет самую слабую, скорбь не вытесняется.

Связи видны в поведении, детерминированно и без лишних движений: раз в две секунды мод смотрит на знакомых мобов в 32 блоках от вас (дальше никто не смотрит), и свободный моб — не в бою, не в разговоре, не в панике, без задания FOLLOW/FLEE/ATTACK, не враждебный по природе, не сидящий и не на поводке — с шансом 1 к 8 идёт к другу, стоящему в 6–24 блоках (короткая цель ходьбы, ванильный ИИ ведёт сам), а от врага ближе 4 блоков отступает; друг скорбящего один раз приходит к нему и стоит рядом 10–20 секунд. Таких прогулок не больше заданного числа в минуту (F7 → «Общее», по умолчанию 6; там же социальное поведение выключается целиком). В промпт попадает блок «Свои» — три самые сильные связи словами («Кузьма (железный голем) — близкий друг, сосед по деревне (сейчас рядом)», «Прохор (житель) погиб на твоих глазах; ты скорбишь по нему», «Серый (волк) — враг, ты его сторонишься») с правилом не пересказывать список, а пользоваться им: сослаться на друга, помянуть погибшего по имени, окликнуть соседа. Друг другого вида рядом считается союзником в трезвой оценке обстановки. `/mobtalk state` печатает связи собеседника. Направленные связи с именами и тегами — основа для следующего шага: слухов в деревне и разговоров мобов между собой.

**Слухи в деревне.** У каждой известной деревни есть хроника: раз в игровой день (или раньше, когда у её жителей накопилось важных событий на 12 очков) один фоновый запрос дешёвой моделью (`backgroundModel`) превращает события и факты важности от 3 всех знакомых жителей за день в 2–4 коротких слуха от третьего лица, у каждого — рассказчик, важность 1–5 и знак (дурно, никак, хорошо для вас). Слух знает сначала только рассказчик; дальше он идёт от знающего к незнающему, когда двое жителей стоят в 8 блоках друг от друга: шанс растёт с важностью и выше между семьёй и друзьями (45 % за встречу для важного слуха, 72 % между своими, не чаще раза в полминуты на пару). Странствующий торговец, постояв рядом с жителем, уносит до трёх самых громких слухов и рассказывает их в следующей деревне уже от себя. Слух теряет вес с каждым днём и забывается на пятый; в деревне не больше 10 слухов, у жителя не больше 6. В промпт жителя идёт блок «Говорят в деревне» (до трёх слухов: «Ладко говорит, что…») с правилом не пересказывать список, а относиться по характеру: сплетник раздувает, скептик сомневается, трусливый опасается. Новичок деревни, с которым вы ещё не говорили, знает её слухи сразу и встречает вас по репутации деревни — балансу знаков по весу («дурная», «добрая» или «смешанная» слава); это строка в промпте, не изменение отношения. Хроника пишется для деревни, в которой вы стоите, после того как в этом мире состоялся хотя бы один разговор. `/mobtalk state` показывает слухи собеседника.

**Мобы заговаривают первыми.** Знакомый мирный моб может заговорить сам, без вашей реплики, по поводу, который игра замечает без модели: вы вернулись к нему после 20 минут отсутствия (отношение не ниже нуля); у него осталась мысль или незакрытое дело с вами (услуга, обещанная сделка) и вы в 6 блоках; вы только что поставили или сломали рядом с ним 8 и больше блоков; только что настала ночь, пошёл дождь или гроза; или рядом стоит его друг, а вы в 12 блоках и ни с кем не говорите. Повод, настрой («поздороваться», «поворчать», «спросить о деле»…) и длину решает решатель (ниже), реплика приходит одним обычным запросом модели и звучит через очередь очевидцев — никогда поверх другой речи, вашей записи или ожидания ответа; незнакомые и враждебные мобы инициативы не проявляют. Не чаще одного раза в минуту на мир (в F7 → «Общее» до шести) и одного раза в пять минут на моба. Если повод — друг рядом, начинается сцена между мобами: 2–4 реплики, первая по поводу, остальные — ответы собеседнику (не вам), следующего говорящего выбирает решатель из друзей в 8 блоках; вы слышите их в 12 блоках. Выключается там же в настройках.

**Решатель.** Кто решает, заговорит ли моб, кто из очевидцев вмешается после пустой болтовни и кто говорит следующим в сцене: **правила** (по умолчанию: шанс из повода, общительности и настроения, ближайший друг отвечает, очевидец вмешивается в половине случаев) или **Jev** — модель решений OpenRouter (`~typesafe/jev-latest`, Decisions API) на вашем ключе OpenRouter: компактное состояние моба (настроение словами и числами, темперамент, отношение, связи, повод, последние события, что сказано — без секретов) и три типизированных вопроса; меньше секунды и около 0,00004 $ за решение. Таймаут 1,5 с, при ошибке или таймауте отвечают правила. Переключатель — F7 → «Общее» → «Кто решает, говорить ли».

**Перемирие с враждебными.** Враждебный вид начинает с −80, но доверие можно заслужить — в основном услугами (+25 за каждую) и покупками. С **+20** наступает перемирие: моб не нападает на этого игрока и не берёт его в цель, пока тот не ударит первым (первый удар сразу роняет отношение до −80). С **+60** моб считает игрока своим: ходит за ним и дерётся за него по просьбе, как приручённый. Отношение и статус («перемирие», «свой») видны в строке Mob Talk. Так открываются и секретные сделки враждебных мобов (порог 30–70).

Мод рассчитан на взрослых игроков. Мобы говорят как живые персонажи с майнкрафтовой спецификой: знают механики, дроп, привычки игроков и старые мемы, подкалывают за кожаную броню и землянку, злятся, хвастаются и угрожают. У каждого из 246 характеров свой голос и примеры реплик; враждебные виды по-настоящему враждебны. Шутки, угрозы и оскорбления не становятся фактами памяти.

Уровень грубости выбирается в F7 → «Общее» → **Дерзость**: «Без мата», «Грубовато», «Мат моментами» (по умолчанию) или «Без тормозов». Злые и грубые персонажи ругаются чаще добрых. На «Мат моментами» и «Без тормозов» модель получает примеры настоящего мата и правило отвечать матом на мат; на «Без тормозов» матерятся и холодно-вежливые персонажи, в своей манере. Уровень стоит последним в промпте и важнее вежливости из описания характера: многие модели по умолчанию тянутся к вежливости. Оскорбления касаются игрового — кривых рук, брони, трусости, — а не реальных национальности, внешности, ориентации или религии. Общий стиль можно дополнить там же в «Общий стиль разговора»: он важнее встроенного стиля.

Реплики обычно в одну-три фразы; верхнюю границу задаёт число слов в меню (по умолчанию 45).

## Сделки, секреты и услуги

Торговать можно с любым из 82 видов. Что продаёт моб и чем берёт, задано в `assets/mobtalk/trades.json` по дропу, среде и лору: пчела меняет мёд на цветы, пиглин — жемчуг и обсидиан на золото, скелет — стрелы, варден — скалк за шерсть (чтобы было тише), иссушитель — звезду только после услуги. Всего 274 сделки, 101 из них секретная.

1. Выберите моба палкой и поговорите: спросите, чем торгует, поторгуйтесь голосом. Цены называет моб, числа проверяет код.
2. Нажмите **B** (или `/mobtalk trade`): открывается обычное окно торговца с личными сделками моба — ваша цена (исходная зачёркнута), подсказки о секретных сделках в строках `???`, обещанная услуга. Покупка — как у жителя: обмен происходит на сервере, словами ничего не передаётся. При открытом окне можно торговаться голосом дальше: уступка сразу меняет цену в окне, моб понимает, какую строку вы выбрали. У жителей и странствующих торговцев личного каталога нет: их единственные товары — ванильные, и торг идёт за строку этого окна (см. ниже); услуги они просят как все.
3. **Секретные сделки** (101 из 274) не видны в начале. Моб дразнит ими и открывает в разговоре, когда отношение дошло до порога (30–70) и, если сделка того требует, вы уже оказали этому мобу хоть одну услугу. Открытая сделка остаётся открытой у этого моба навсегда.
4. **Услуги** моб придумывает сам, когда вы предлагаете помощь, спрашиваете, что ему нужно, или добиваетесь секрета. Предмет и количество каждый раз выбирает игра случайно — три кандидата из пула в 267 ванильных предметов (еда, растения, блоки, руда, снаряжение, пластинки…), а моб выбирает один из них и сочиняет, зачем он ему именно сейчас. Услуга — личный долг перед тем, кто попросил: принять её может только он, награда (+25 к отношению и то, что он сам пообещал — открыть секретную сделку и/или сбить цену до 50%, навсегда) тоже его. Соседи по деревне знают о ваших делах с другими жителями как о слухах: не просят того же и чужое не засчитывают.

Правила цены одинаковы для всех: за один шаг торга цена падает **не больше чем вдвое** от текущей (округление в пользу покупателя), за все шаги — **не ниже 10%** исходной. Сбитая цена **постоянна** для этого игрока и этого моба: не возвращается после покупки и не истекает, а в следующей сессии её можно сбить ещё. Сессия — три уступки, следующая через 20 минут. При отношении −40 и ниже уступок нет. У ценных сделок есть дневной лимит (1–2 обмена в игровой день).

Цены, услуги и открытые секреты хранятся для каждого моба отдельно; всё в памяти мира (`data/mobtalk/conversations.json`), для каждого игрока отдельно. Отношение моба к вам видно в строке Mob Talk над инвентарём и в заголовке окна сделок.

### Житель: торг в окне торговли

У жителя кроме своих сделок есть обычное окно торговли, и уступку в нём тоже можно выторговать голосом:

1. Откройте торговлю, выберите строку, удерживайте **V** и предложите цену. Житель становится собеседником автоматически.
2. Уступка сразу встаёт в окно; в чате появляется `[Mob Talk] Цена в окне торговли: …`. Без этой строки цена не менялась.
3. Цена действует **постоянно** — после покупки не возвращается, переоткрытие окна и перезаход её не сбрасывают. Три уступки за сессию, следующая сессия через 20 игровых минут, от уже сбитой цены вниз до 10% исходного количества.

| Обычные условия | Шаг 1 | Шаг 2 | Шаг 3 (предел) |
|---|---|---|---|
| 22 моркови за 1 изумруд | до 11 | до 5 | до 2 |
| 32 палки за 1 изумруд | до 16 | до 8 | до 4 |
| 20 изумрудов за товар | до 10 | до 5 | до 2 |

Уступка касается первого входного предмета; второй ингредиент и результат не меняются. Отказ (DECLINE) закрывает сессию, но цену сохраняет. Удар по жителю или смена условий сделки снимают уступку.

### Житель: сделка словами без окна

Торговаться с жителем можно и не открывая окно — просто глядя на него и удерживая **V**. Модель видит его строки с текущей ценой и допустимыми ценами (`mobDetails.bargaining.spoken`), и если житель соглашается («ладно, восемнадцать морковок за изумруд»), игра добавляет в его обычное окно торговли **отдельную строку по обещанной цене**: те же предметы, одна покупка, 10 игровых минут. В чате появляется `[Mob Talk] Сделка в окне торговли: 1× Изумруд за 18× Морковь — одна покупка, 10 мин (ПКМ по жителю)`; откройте торговлю правым кликом и купите. Правила те же, что у уступки в окне: не больше чем вдвое за шаг от текущей цены (уже сбитая постоянная цена учитывается), не ниже 10% исходного количества, не больше трёх понижений одного обещания; у жителя одно обещание за раз, новое заменяет старое. Строка не сохраняется в мир (снимается при записи жителя, выгрузке, смерти, выходе из мира и по истечении срока) и не трогает ванильные строки, цены и уровень. Покупка по обещанию — выполненная сделка: +5 к отношению, запись в памяти жителя «купил по договорённости…». Встревоженный или недоверчивый житель (состояние ниже 25) ничего не обещает, при отношении −40 и ниже — тоже.

### Индикатор хода торга

Пока идёт торг (две минуты после реплики с уступкой, согласием или отказом), в строке Mob Talk рядом со словом состояния показывается «торг: **склоняется**» (зелёным), «**не уверен**» (жёлтым) или «**против**» (красным). Слово считается кодом, без модели: последний ход моба (уступка, согласие, отказ), насколько далеко он пошёл к нижней границе цены, попало ли ваше число в допустимый диапазон, и как он к вам сейчас относится — доверие и настроение состояния плюс отношение; моб, который в тревоге или недоверии не торгует, всегда «против». Пересчитывается каждую секунду вместе с состоянием. Выключается в F7 → «Общее» → «Ход торга в строке Mob Talk».

## Действия мобов

Моб может следовать, убегать, атаковать допустимую цель или отказаться. Решение принимается после ответа; движение и бой выполняются обычными игровыми механизмами.

FOLLOW сохраняется при выборе другого собеседника и после перезапуска мира. Выгрузка сущности приостанавливает его. Удар следовавшего за вами моба отменяет следование.

**Просьбы к друзьям.** Скажите словами — модель сама выберет действие (или выберите его в F7 → «Просьба»); друг может и сам предложить «постою здесь» или «присмотрю за тобой».

| Действие | Что делает | Кому доступно |
|---|---|---|
| STAY — «жди здесь» | Стоит на месте, смотрит на вас, если вы рядом; сдвинутый — возвращается. | Приручённому вами или при отношении от +20 (враждебному — только в перемирии). |
| GUARD — «охраняй меня» / «охраняй это место» | Держится в 3–6 блоках от вас (или от места), нападает на враждебных мобов, подошедших ближе 8 блоков, после боя возвращается; погоню дальше 16 блоков бросает. Мобов в перемирии с вами и спокойных нейтралов не трогает. | Бойцам (волк, голем, враждебные…), приручённым вами или при отношении от +60. Голем деревни — тоже только от +60. |
| SPARE — «не трогай её/его» | Враждебный моб не берёт в цель указанного моба рядом (в перемирии) или вас (до перемирия), бросает начатую атаку на него. | Враждебным видам. |

Каждая просьба длится 10 игровых минут; повтор той же просьбы молча продлевает её. Конец — время вышло, вы ушли дальше 48 блоков или в другой мир (STAY, GUARD), цели больше нет, вы ударили моба, перемирие нарушено (SPARE); в чат приходит сообщение с причиной. Отпустить словами — моб ответит STOP; другое действие (следовать, уйти, атаковать) тоже заменяет просьбу, а обычный разговор её не снимает. `/mobtalk stop` или кнопка отмены снимают всё сразу. `/mobtalk state` показывает активные просьбы и сколько минут осталось. После перезапуска мира просьбы не восстанавливаются.

Мирные мобы могут дать сдачи. Удар игрока вызывает ответную атаку до 20 секунд; повторный удар обновляет это время. Для нападения мирного моба на игрока нужно отношение не выше −40 либо настоящая текущая агрессия; враждебным видам личная ссора для боя не требуется, но перемирие (отношение от +20) запрещает атаку и им. Моб может выбрать атаку и в разговоре, если достаточно разозлён.

**Ненависть с последствиями.** Раз в секунду знакомый мирный моб (вы с ним говорили или у него есть история) с отношением −40 и ниже, который видит вас в 12 блоках, действует сам: боец (есть урон, зубы или оружие) нападает, если по оценке обстановки силы равны или он сильнее; остальные убегают на 20 секунд, а житель при этом зовёт железных големов в 16 блоках (голем, у которого с вами перемирие от +20, не вмешивается). Так жителя, доведённого до −100, не нужно бить, чтобы увидеть ответ. Хозяина питомца, творческий режим и наблюдателя это не касается.

Големы, волки и другие боевые виды используют штатную атаку. Животные и жители без своей боевой механики получают временный ближний удар: обычные путь, дистанция, видимость и перезарядка Minecraft; при отсутствии своего атрибута урона — 2 единицы. STOP и выгрузка снимают временное управление. Творческий режим и наблюдатель сохраняют неуязвимость, мирная сложность сохраняет свои правила урона.

Действия зависят от вида и состояния. Рыбы двигаются в воде. Гаст, слизни, магмовый куб и иссушитель поддерживают родную атаку; дракон сохраняет боевые фазы. Взрывы и снаряды настоящие, с соблюдением правил мира. STOP возвращает обычное поведение, включая природную враждебность.

## Место

Перед ответом моб понимает форму места, в котором стоит, — локально, без запросов к нейросети. На интегрированном сервере вокруг его ног снимается коробка блоков 25×17×25, и по ней проходит заливка проходимых клеток с учётом тела: шаг вверх на блок, падение до трёх, плавание (но не против течения), лестницы; двери — граница комнаты. Из заливки выходят размеры, выходы по сторонам света, из чего стены (бедрок — «не прокопать», стекло — «видно насквозь», забор — «не перепрыгнуть»), небо над головой, вода и течение, обрывы, лава рядом, куда ведёт дно, воронка ли это, где игрок (внутри, снаружи, выше, видно ли через проём или стекло). Вид места: открытое место, яма, закрытая камера, воронка, клетка, загон, помещение, коридор, тупик, возвышение, вода.

Блоки рядом группируются в объекты, как в SmartPlay: «стена из бедрок 4×3 вплотную к северу: не прокопать», «лава 2×2 в 4 блоках к востоку, ниже: смертельно», «дверь в 4 блоках к востоку, открыта», «вода под ногами, течёт на юг» — восемь самых значимых (опасные, редкие, близкие, крупные). Этот список заменил сырой перечень блоков в снимке, токенов не прибавилось.

Мод помнит, что вы ставили и ломали последние 5 минут. Моб отличает «сам провалился» от «меня замуровали», а знакомый моб, которого вы только что закрыли или окопали, получает событие в память: «Игрок замуровал тебя: поставил вокруг 20 блоков».

Маленький классификатор формы (3D-свёрточная сеть на кубе 16³, 300 КБ весов, чистая Java без нативных библиотек, вне серверного потока) добавляет догадку о назначении: «похоже на: дом / ферма / ловушка (уверенность 93 %)». Факты заливки главнее — так и сказано модели в блоке «Место» системного промпта, вместе с правилом использовать их, а не пересказывать, и верить им при противоречии. Строка «бежать некуда» в оценке обстановки называет, что именно запирает; FLEE взаперти по-прежнему превращается в NONE. Подробности, генератор сцен и точность классификатора — [docs/space-analysis.md](docs/space-analysis.md).

### Сравнение распознавания

Запишите одну фразу удержанием клавиши, отметьте модели и запустите сравнение. Они получают один WAV последовательно. Результаты показывают текст, фактическое устройство, время подготовки и распознавания. Запись можно прослушать и применить понравившуюся модель.

Доступны `small`, `medium`, `large-v2`, `large-v3`, `large-v3-turbo`. По умолчанию `ru`, `beam_size=5`, устройство `auto`. Большие модели требуют больше ресурсов; при нехватке видеопамяти выберите меньшую или CPU. Одновременно загружена одна модель. Запись ограничена 15 секундами и очищается при закрытии проверки.

Старый отдельно запущенный Whisper нужно обновить/перезапустить; автоматически запускаемый помощник копируется из нового JAR. Адрес: `http://127.0.0.1:63919`.

### Своя (дообученная) модель Whisper

Кроме моделей из списка, `whisperModel` принимает имя папки CTranslate2 в каталоге моделей помощника (`<папка MobTalk>/models/<имя>`, внутри `model.bin`) или абсолютный путь к такой папке. Пример для модели, дообученной на голосе игрока (`scripts/train-whisper.ps1`, подробности — [docs/whisper-finetune.md](docs/whisper-finetune.md)): в `config/mobtalk.json` укажите `"whisperModel": "mobtalk-small-ru"`; пока она выбрана, она видна в списке «Модель» вкладки «Микрофон». Неизвестные имена не скачиваются: помощник сообщит, что модель недоступна. Вернуться: `"whisperModel": "large-v3"` или выбрать `large-v3` в меню.

### Голоса и расходы

Каталог: 246 разных основных голосов, по 3 на вид, и отдельные видовые резервы. Разные виды не делят голоса. Первые три особи вида получают разные варианты, далее выбираются наименее занятые.

Подбор основан на публичных карточках ElevenLabs, описаниях и русских языковых метаданных. Публичное превью и успешная генерация Flash v2.5 показываются разными статусами. Массовые платные пробы не выполняются: успешный OpenRouter отмечается после явной проверки или игровой озвучки. При временной сетевой ошибке остаются субтитры.

LLM и TTS расходуют кредиты того провайдера, который выбран для каждого из них (OpenRouter или Venice); локальное распознавание и готовые публичные превью не вызывают платную модель. Java нужен HTTPS-доступ к `openrouter.ai` (и к `api.venice.ai` для Venice); первая загрузка весов Whisper требует HuggingFace.

Если провайдер не принимает строгую JSON-схему вместе с `temperature` (так у Claude Haiku 5.5), мод повторяет запрос без `temperature`, затем пробует совместимый JSON-режим; все игровые проверки остаются в коде. HTTP 429 означает ограничение запросов на стороне OpenRouter/провайдера: можно подождать или выбрать другую текстовую модель в F7.

В торге модель называет итоговую цену, а код проверяет её по разрешённым ценам выбранной строки. Если житель называет цену, которую торг не применил (например, «теперь по 18» без уступки или «восемь», когда в окно ушло бы 19), ответ не озвучивается: модель получает до двух исправлений, и последнее идёт уже без торга, так что вместо ошибки звучит обычная реплика. Просьба о скидке на другой товар превращается в совет выбрать его строку в окне. История и память обновляются после успешной проверки ответа игрой.

Все запросы к OpenRouter идут через одно общее соединение. Пока моб выбран, мод раз в 10–20 секунд простоя шлёт бесплатный запрос информации о ключе, чтобы соединение не закрылось: через некоторые локальные прокси новое соединение стоит несколько секунд.

Проверка подключения использует [информацию о текущем API-ключе](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-api-key); она не запускает LLM или TTS.

### Скорость

Время ответа складывается из LLM, озвучки и распознавания. Мод делает всё, что может параллельно: реплика стримится и озвучка стартует по первым словам, очевидцы думают одновременно с голосом собеседника, биография пишется внутри первого ответа, запросов в полёте не больше трёх. Для рассуждающих моделей OpenRouter (gpt-6-luna и подобные) параметр `reasoningEffort` в `mobtalk.json` по умолчанию `minimal`: без него модель думает по несколько секунд перед каждой фразой (в пробе 2,5 с против 17 с). Остальное — скорость самой модели: если ответы всё равно долгие, выберите модель побыстрее в F7.

### Рекомендуемые модели

Октябрь 2026: проверка на всех 82 видах (знакомство, дроп, хамство на «Без тормозов», комплимент) через реальный промпт мода.

| Модель | Где | Ответ | Сильные стороны | Слабые стороны |
|---|---|---|---|---|
| `openai/gpt-6-luna` (по умолчанию) | OpenRouter, Venice `openai-gpt-6-luna` | ~3.6 с | Самая точная по механикам и дропу, ругается по ситуации, не грубит без повода | Около 1% ответов OpenRouter обрывает |
| `anthropic/claude-haiku-5.5` | OpenRouter, Venice `claude-haiku-5-5` | ~4 с | Самые живые реплики, держит образ, мат на хамство всегда | Чуть длиннее и медленнее |

## Разработка и проверка

Сборка: `./scripts/verify.ps1 -Tests`.
Самотест в настоящей игре: запустите инстанс с JVM-параметром `-Dmobtalk.selftest=<папка мира>` (в Prism — «Настройки инстанса → Java → Аргументы JVM»; мир лучше скопировать). Мод сам загрузит мир с титульного экрана, построит площадку в небе, призовёт жителя, корову и голема, проверит прицел, ответ с озвучкой, реплику и штраф очевидца, бегство ненавидящего жителя и вызов голема, запишет шаги как `[selftest]` в `logs/latest.log` и закроет игру. Тратит кредиты LLM и TTS на три-четыре реплики.
Локальный backend: `py -3.12 -m unittest discover -s tools -p test_whisper_server.py`.
Результат: `build/libs/mobtalk-0.5.0.jar`.

### Как устроен код

`core` — чистая Java без Minecraft, покрыта тестами:

| Класс | За что отвечает |
|---|---|
| `ConversationEngine` | Один разговор: промпт → ответ → ранняя озвучка → проверка → фиксация в памяти; биография при первой встрече. |
| `OpenRouterConversationClient` | HTTP к OpenRouter/Venice, стриминг реплики, цикл из двух исправлений, провайдерские особенности. |
| `MobPrompt` + `PromptTexts` | Сборка системного промпта (вид, история, характер, настроение, игрок) и сообщения с данными; все тексты правил — в `PromptTexts`. |
| `ReplySchema` | Строгие JSON-схемы ответа и биографии, сужение enum под снимок. |
| `AnswerValidator` | Проверка ответа модели по снимку: действия, торг жителя, свои сделки, секреты, услуги, «необеспеченные» цены и приёмки, язык. |
| `TradingView` | Типизированное чтение `mobDetails.trading`/`bargaining` — общее для промпта и валидатора. |
| `BiographyWriter` | Запрос и разбор имени, истории, желания, тайны и истории деревни. |
| `Situation` | Кто кого победит: оружие и броня игрока против тела моба и сородичей; блок «Трезвая оценка» в промпте. |
| `MobState` | Состояние моба: четыре оси с точкой покоя из темперамента и затуханием по времени, события-сдвиги, перевод в слова для промпта и HUD, последняя мысль. |
| `place/*` + `PlacePrompt` | Место: сетка блоков `VoxelGrid`, заливка `Place` (яма, камера, воронка, клетка, выходы, стены, вода, игрок, кто строил), объекты `PlaceObjects`, генератор сцен `SceneGenerator` + датасет, классификатор `PlaceClassifier` на чистой Java; блок «Место» в промпте. |
| `MobRelations` + `SocialRules` | Отношения между мобами: до 12 направленных связей на моба с оценкой, тегами (друг, соперник, сородич, семья, скорбит) и затуханием; чистые правила, кому подойти к другу, отойти от врага и навестить скорбящего. |
| `VillageRumors` | Хроника деревни: слухи с рассказчиком, важностью и знаком, кто что слышал, распространение при встречах и через торговца, затухание, репутация игрока, фоновый запрос хроники. |
| `Initiative`, `Decider` (`RuleDecider`, `JevDecider`), `DecisionState` | Поводы заговорить первым, бюджеты, сцена между мобами; решатель по правилам и через Decisions API с откатом; компактное состояние для решений. |
| `ConversationStore` + `WorldMemoryFile` + `ProfileDefaults` | Память мира: профили, отношения, что знает вид, деревни; файл с миграциями и атомарной записью; значения по умолчанию профиля. |
| `MemoryRanking` + `MemoryFact` | Важность фактов и событий, оценка «важность × свежесть», сортировка в промпте и вытеснение при переполнении; миграция старого текста памяти. |
| `ConversationSummary` + `Reflection` + `BackgroundTasks` | Сводка разговора при его окончании, выводы об игроке раз в несколько реплик; одна фоновая очередь из одного потока, не задерживающая ответы. |
| `Trading`, `Bargaining`, `TradeCatalog`, `FavorItems` | Правила цен, уступок жителя, каталог сделок, пул предметов для услуг. |
| `SpokenOffer` | Обещание жителя при закрытом окне: допустимые цены, раунды, срок, блок для модели и проверка её ответа. |
| `BargainMeter` | Индикатор хода торга: слово «склоняется / не уверен / против» из последнего хода, цены, состояния и отношения. |
| `Mischief` | Проступки без ударов: штрафы по видам, кулдауны, учёт своих блоков. |
| `SpeciesCatalog` | 82 вида, архетипы, голоса, привычки/желание/тайна. |

`client` — Fabric: `MobTalkClient` (клавиши, запись, конвейер разговора, HUD), `MerchantSession` (речь внутри торгового окна), `MobTalkCommands` (`/mobtalk`), `SettingsController` (связь меню F7 с клиентом), `InitiativeVoice` (мобы заговаривают первыми, сцены моб–моб, запуск хроники), `game/*` — integrated server (снимок мира, поводы для инициативы `InitiativeController`, действия, окно сделок `MobMerchant`, торг жителя `VillagerBargaining`, обещания жителя как строки окна `TradeBridge`, проступки на глазах у деревни `MischiefWatch`, миксины).

Целевые тесты используют локальные HTTP-фикстуры и подставную модель Whisper. Это не проверка живого микрофона или всех 246 голосов через платный API.
