# Mob Talk 🗣️

Самостоятельный Fabric-мод для одиночной игры: выберите обычного моба палкой
и разговаривайте с ним в микрофон. Whisper распознаёт речь локально,
OpenRouter LLM отвечает с учётом окружения и памяти, ElevenLabs озвучивает ответ
из позиции моба. Viewer Parrots для работы не нужен.

## Установка

Нужны Minecraft Java **1.21.1**, Java **21**, Fabric Loader **0.19.5**
и Fabric API **0.116.17+1.21.1**.
Для локального распознавания также нужны Python **3.12** и PowerShell **7**.

1. Положите готовый `mobtalk-0.1.0.jar` и Fabric API в `mods` Minecraft-инстанса.
2. В PowerShell 7 из папки проекта выполните `scripts/setup-whisper.ps1`.
   Помощник создаст отдельное Python-окружение и скачает модель `small` один раз.
   На NVIDIA он также ставит CUDA/cuDNN в это окружение; для установки только
   на CPU используйте `scripts/setup-whisper.ps1 -Device cpu`.
3. В `config/mobtalk-openrouter-token.txt` сохраните OpenRouter API-ключ одной строкой.
   Альтернатива — `OPENROUTER_API_KEY`. На этом ПК также поддерживается уже
   настроенный локальный DPAPI-ключ тестера голосов.
4. Запустите Minecraft и одиночный мир. Мод автоматически запустит локальный Whisper.

Установка из собранного проекта в Prism:

```powershell
.\scripts\install-prism.ps1 -Instance 'имя-папки-инстанса'
```

## Управление

- **ПКМ палкой по мобу** — выбрать собеседника.
- **Shift + ПКМ палкой** — снять выбор.
- **Удерживайте V** — говорите; **отпустите V** — отправьте реплику.
- Клавиша меняется в стандартных настройках управления Minecraft.
- Статусы показываются над хотбаром, распознанная речь и ответы — в чате.
- `/mobtalk say Текст` — текстовая реплика выбранному мобу, для проверки без микрофона.
- `/mobtalk status` — текущее состояние.
- `/mobtalk clear` — снять выбор.
- `/mobtalk reload` — перечитать настройки.
- `/mobtalk mic list` — показать названия микрофонов для `microphoneName` в конфиге.

У каждой птицы, коровы, жителя или другого выбранного моба свои голос,
характер и память по UUID. Они сохраняются в `data/mobtalk` внутри папки мира.
Моб продолжает своё обычное поведение. Разговор не выполняет игровые команды LLM.

## Настройки

`config/mobtalk.json` создаётся автоматически. По умолчанию:

- LLM: `google/gemini-2.5-flash-lite`;
- озвучка: `elevenlabs/eleven-v4-turbo` через OpenRouter;
- Whisper: многоязычная `small`, язык `ru`, GPU auto с CPU fallback;
- запись до 15 секунд, ответ до 45 слов, расстояние до 16 блоков;
- последние 6 обменов репликами и короткая память каждого моба.

Пустая запись не отправляется в LLM. Один разговор выполняется за раз.
Смена собеседника или мира, смерть и выгрузка моба отменяют устаревший ответ.
Сетевые запросы и распознавание выполняются в фоне.

Whisper слушает только `127.0.0.1:63919`. Для LLM и TTS процессу Java
нужен HTTPS-доступ к `openrouter.ai`, в том числе через ваш VPN.
LLM и озвучка используют платные кредиты OpenRouter.

Чтобы отключить мод, закройте игру и уберите его JAR из `mods`.
Чтобы временно отключить разговоры, установите `enabled: false` и перечитайте конфиг.

## Проверено на этом ПК

Сборка JAR и короткие тесты ядра/аудио/помощника прошли. Whisper `small`
распознал русскую тестовую запись на GPU (`cuda`). Настоящие LLM и TTS
OpenRouter вернули текст и PCM; в отдельном мире Minecraft выбор палкой,
текстовый разговор и сохранение памяти по UUID работают. Живую запись
с вашего микрофона нужно проверить удержанием V.
