# Parrot Cages

Небольшой Fabric-мод для Minecraft 1.21.1: клетки для попугаев трёх размеров.

| Клетка | Размер (Ш×В×Г) | Рецепт |
|---|---|---|
| Маленькая | 1×2×1 | железный самородок, 4 решётки, 3 дубовые плиты |
| Средняя | 2×2×2 | 2 железных слитка, 3 решётки, 3 еловые плиты |
| Большая | 3×3×3 | 2 слитка, железный блок, 3 решётки, 3 плиты тёмного дуба |

Все клетки лежат во вкладке «Функциональные блоки» творческого инвентаря.

## Как пользоваться

- Поставьте клетку: кликнутая точка становится нижней частью клетки, остальное
  достраивается само, если хватает места.
- ПКМ по пустой клетке сажает в неё ближайшего к вам свободного попугая (в радиусе 8 блоков).
  Чужих ручных попугаев клетка не берёт.
- ПКМ по занятой клетке показывает, кто в ней сидит. Присядьте и нажмите ПКМ, чтобы выпустить
  птицу рядом с собой. Сломанная клетка тоже выпускает птицу.

Попугай остаётся живой сущностью: летает внутри, его видно сквозь прутья. Стенки держат его
физически, а если птицу всё-таки вынесло наружу (телепорт другого мода), клетка возвращает её.
Ручной ванильный попугай в клетке садится, чтобы не запрыгнуть хозяину на плечо.

## Совместимость

Птица в клетке помечена тегом сущности `parrotcages.caged`. Viewer Parrots 1.2.1+ по нему
отклоняет `!come`, `!follow`, `!freefollow` и `!arm` с ответом «Попугай сидит в клетке»; танцы,
эмоции, речь, шапки и остальное работают прямо в клетке.

Если удалить мод, клетки исчезнут из мира, а попугаи останутся там, где были. Viewer Parrots
без Parrot Cages тег игнорирует.
