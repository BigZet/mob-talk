# Mob Talk 🗣️

**Поговори с любым мобом в Minecraft голосом.** Выбери моба палкой, зажми V и скажи что угодно в микрофон — моб ответит своим голосом. Без готовых фраз: у каждого свой характер, память и отношение к тебе.

## Что умеют мобы

- 🧟 **Действуют по разговору.** Нахамил жителю — убежит. Довёл крипера — рванёт по-настоящему. Попросил прирученного волка — пойдёт за тобой или кинется на зомби. А может и отказаться.
- 💰 **Торгуют и торгуются — все 82 вида.** У каждого свой товар и своя валюта: корова отдаст молоко за пшеницу, зомби — морковку «от последнего парня» за свинину, эндермен — жемчуг за дёрн. Сбитая цена остаётся навсегда и может падать дальше; у жителя уступка сразу встаёт в окно торговли.
- 🗝️ **Прячут секретные сделки и просят об услугах.** Моб сам придумывает, что ему принести и зачем; принеси — и он откроет то, чего не показывал, или скинет цену.
- 🌱 **Живут своей жизнью.** У каждого вида свои речевые привычки, цель в жизни и тайна, которую выдают только друзьям, а разговор начинается из настроения: ночь, дождь, недавний удар.
- 🧠 **Помнят и замечают.** Видят, что у тебя в руках, во что ты одет, кто бродит рядом. Помнят, как ты их бил, оскорблял или помогал.
- 🐺 **82 вида с характерами.** Гордый волк не признает, что он пёсик, даже в ошейнике. Кролик требует держаться в пяти блоках. Овца уверена, что твой «милый пёсик» её сожрёт.
- 🤬 **Дерзость на выбор:** от «без мата» до «без тормозов».

Minecraft 1.21.1 · Fabric · одиночная игра. Нужен ключ [OpenRouter](https://openrouter.ai): через него работают нейросеть и голоса (платно, по факту использования).

**Как это устроено:** речь распознаётся локально (Whisper), ответ пишет LLM через OpenRouter с учётом личности моба и того, что происходит в мире, а озвучивает ElevenLabs Eleven Flash v2.5 из позиции моба. Всё, что ниже, — установка и подробности.

## Установка с нуля

Нужны Minecraft Java **1.21.1**, Java **21**, Fabric Loader **0.19.5**, Fabric API **0.116.17+1.21.1**, Python **3.12** и PowerShell **7**.

1. Положите `mobtalk-0.3.0.jar` и Fabric API в `mods` своего инстанса.
2. Из папки проекта выполните в PowerShell 7: `./scripts/setup-whisper.ps1 -NoStart`. Скрипт создаёт отдельное окружение `%LOCALAPPDATA%/MobTalk`, устанавливает совместимые библиотеки и скачивает модель. По умолчанию `large-v3`; для лёгкого начала добавьте `-Model small`, для CPU — `-Device cpu`. Остальные модели загружаются из игрового меню.
3. Нажмите в игре **F7 → Общее**, вставьте OpenRouter API-ключ в поле «API-ключ» (кнопка «Вставить» или Ctrl+V) и нажмите «Сохранить ключ». Ключ скрыт звёздочками, шифруется Windows (DPAPI) для вашей учётной записи в `%LOCALAPPDATA%\MobTalk\openrouter-key.dpapi` и не попадает в `mobtalk.json`, JAR или память мира. По-прежнему поддерживаются `OPENROUTER_API_KEY` (важнее ключа из меню) и `config/mobtalk-openrouter-token.txt`.
   Ответы мобов можно получать и через **Venice**: в F7 → «Общее» переключите «Провайдер» на Venice, вставьте ключ Venice в появившийся раздел и укажите модель (по умолчанию `deepseek-v4-1-flash`). Озвучка в любом случае идёт через OpenRouter (голоса ElevenLabs), поэтому ключ OpenRouter нужен и с Venice; без него ответы будут только текстом. Ключ Venice хранится так же: `%LOCALAPPDATA%\MobTalk\venice-key.dpapi`, `VENICE_API_KEY` или `config/mobtalk-venice-token.txt`.
4. Запустите одиночный мир, нажмите **F7**, выберите микрофон и откройте его проверку.

Обновление из собранного проекта в Prism: `./scripts/install-prism.ps1 -Instance '1.21.1-fabric-dev'`. Старые JAR сохраняются в `mobtalk-backups`. Для загрузки версии перезапустите Minecraft. Viewer Parrots устанавливается отдельно и не требуется для Mob Talk.

## Управление

- **ПКМ палкой** по мобу — выбрать собеседника; **Shift+ПКМ палкой** — снять выбор.
- **Удерживать V** — говорить, отпустить — отправить. Клавиша меняется в настройках управления Minecraft.
- **B** или `/mobtalk trade` — ванильное окно торговли с личными сделками выбранного моба: своя цена с зачёркнутой исходной, строки `???` с подсказками о секретных сделках, текущая услуга. У жителя и странствующего торговца B открывает то же окно, что и ПКМ, — их товар только там. Повторное **B** закрывает окно. В заголовке и в строке HUD видно отношение моба к вам.
- **F7**, `/mobtalk` или **Esc → Mob Talk** — настройки.
- `/mobtalk say Текст` — разговор без микрофона.
- `/mobtalk follow`, `/mobtalk flee`, `/mobtalk attack player` — попросить действие; решение принимает моб.
- `/mobtalk attack e1` — попросить атаковать существо с идентификатором из текущего контекста.
- `/mobtalk stop` — отменить действие; `/mobtalk stop_all` — остановить управление всеми последователями.
- `/mobtalk status`, `clear`, `reload`, `mic list` — состояние, снятие выбора, перечитывание настроек и устройства.

## Характер и память

У всех 82 ванильных видов отдельные профили и по три архетипа. UUID получает постоянные голос, архетип и индивидуальные особенности. Имя в игре автоматически не меняется. Настоящие профессия жителя, характер панды, возраст, хозяин питомца и агрессия учитываются отдельно.

При первой встрече (выбор палкой) моб получает **свою историю**: модель придумывает ему имя-прозвище и биографию в несколько предложений — откуда он, что пережил, что ищет, — и дальше говорит из неё; имя видно в чате. У жителя с первым встреченным жителем деревни рождается и **история деревни** (название, как возникла, чем славится, беда или легенда); соседи в радиусе 160 блоков от колокола или дома первого жителя наследуют её и не выдумывают свою. Истории хранятся в памяти мира.

У каждого вида есть **речевые привычки** (фирменные словечки, что бесит и что смешит), **цель в жизни** (крипер хочет поймать молнию и попасть в красивый дом, житель — колокол на площадь) и **тайна**, которую моб выдаёт только при отношении от 60; чужому лишь намекает. Промпт начинается с этого, а не с торговли: моб не перечисляет товары без вопроса и не говорит как продавец. Разговор стартует из состояния — код описывает модели, цел ли моб, горит ли, мокнет под дождём или сидит под крышей, ночь ли, били ли его недавно и голоден ли игрок.

Моб получает свежие сведения об обеих руках, снаряжении, своём состоянии, времени, погоде, биоме, близких существах и объектах вокруг. Варден воспринимает доступные ему звуки и вибрации.

История по умолчанию — 24 обмена, в меню до 64. На диске до 100 обменов и резюме до 4000 символов. После каждого ответа модель сообщает только новые факты (до 300 символов), мод дописывает их в резюме и при переполнении забывает самые старые строки.

Ответ модели приходит потоком: как только готов текст реплики, мод начинает озвучку, не дожидаясь фактов и действия, а звук играет по первым байтам. Если реплика после проверок изменится или будет отклонена, ранняя озвучка отбрасывается. Память: `data/mobtalk/conversations.json` в мире; перед миграцией создаётся `conversations.v1.backup.json`.

Мобы помнят настоящие удары игрока и его снарядов, включая события до знакомства палкой. Урон окружения не обвиняет игрока. Извинения, настоящая помощь, покупки и выполненные услуги постепенно улучшают отношение.

**Перемирие с враждебными.** Враждебный вид начинает с −80, но доверие можно заслужить — в основном услугами (+25 за каждую) и покупками. С **+20** наступает перемирие: моб не нападает на этого игрока и не берёт его в цель, пока тот не ударит первым (первый удар сразу роняет отношение до −80). С **+60** моб считает игрока своим: ходит за ним и дерётся за него по просьбе, как приручённый. Отношение и статус («перемирие», «свой») видны в строке Mob Talk. Так открываются и секретные сделки враждебных мобов (порог 30–70).

Мод рассчитан на взрослых игроков. Мобы говорят как живые персонажи с майнкрафтовой спецификой: знают механики, дроп, привычки игроков и старые мемы, подкалывают за кожаную броню и землянку, злятся, хвастаются и угрожают. У каждого из 246 характеров свой голос и примеры реплик; враждебные виды по-настоящему враждебны. Шутки, угрозы и оскорбления не становятся фактами памяти.

Уровень грубости выбирается в F7 → «Общее» → **Дерзость**: «Без мата», «Грубовато», «Мат моментами» (по умолчанию) или «Без тормозов». Злые и грубые персонажи ругаются чаще добрых. На «Мат моментами» и «Без тормозов» модель получает примеры настоящего мата и правило отвечать матом на мат; на «Без тормозов» матерятся и холодно-вежливые персонажи, в своей манере. Уровень стоит последним в промпте и важнее вежливости из описания характера: многие модели по умолчанию тянутся к вежливости. Оскорбления касаются игрового — кривых рук, брони, трусости, — а не реальных национальности, внешности, ориентации или религии. Общий стиль можно дополнить там же в «Общий стиль разговора»: он важнее встроенного стиля.

Реплики обычно в одну-три фразы; верхнюю границу задаёт число слов в меню (по умолчанию 45).

## Сделки, секреты и услуги

Торговать можно с любым из 82 видов. Что продаёт моб и чем берёт, задано в `assets/mobtalk/trades.json` по дропу, среде и лору: пчела меняет мёд на цветы, пиглин — жемчуг и обсидиан на золото, скелет — стрелы, варден — скалк за шерсть (чтобы было тише), иссушитель — звезду только после услуги. Всего 274 сделки, 101 из них секретная.

1. Выберите моба палкой и поговорите: спросите, чем торгует, поторгуйтесь голосом. Цены называет моб, числа проверяет код.
2. Нажмите **B** (или `/mobtalk trade`): открывается обычное окно торговца с личными сделками моба — ваша цена (исходная зачёркнута), подсказки о секретных сделках в строках `???`, обещанная услуга. Покупка — как у жителя: обмен происходит на сервере, словами ничего не передаётся. При открытом окне можно торговаться голосом дальше: уступка сразу меняет цену в окне, моб понимает, какую строку вы выбрали. У жителей и странствующих торговцев личного каталога нет: их единственные товары — ванильные, и торг идёт за строку этого окна (см. ниже); услуги они просят как все.
3. **Секретные сделки** (101 из 274) не видны в начале. Моб дразнит ими и открывает в разговоре, когда отношение дошло до порога (30–70) и, если сделка того требует, вы уже оказали этому мобу хоть одну услугу. Открытая сделка остаётся открытой у этого моба навсегда.
4. **Услуги** моб придумывает сам, когда вы предлагаете помощь, спрашиваете, что ему нужно, или добиваетесь секрета. Предмет и количество каждый раз выбирает игра случайно — три кандидата из пула в 267 ванильных предметов (еда, растения, блоки, руда, снаряжение, пластинки…), а моб выбирает один из них и сочиняет, зачем он ему именно сейчас. Услуга — личный долг перед тем, кто попросил: принять её может только он, награда (+25 к отношению и то, что он сам пообещал — открыть секретную сделку и/или сбить цену до 50%, навсегда) тоже его. Соседи по деревне знают о ваших делах с другими жителями как о слухах: не просят того же и чужое не засчитывают.

Правила цены одинаковы для всех: за один шаг торга цена падает **не больше чем вдвое** от текущей (округление в пользу покупателя), за все шаги — **не ниже 10%** исходной. Сбитая цена **постоянна** для этого игрока и этого моба: не возвращается после покупки и не истекает, а в следующей сессии её можно сбить ещё. Сессия — три уступки, следующая через 20 минут. При отношении −40 и ниже уступок нет. У ценных сделок есть дневной лимит (1–2 обмена в игровой день).

Цены, услуги и открытые секреты хранятся для каждого моба отдельно; всё в памяти мира (`data/mobtalk/conversations.json`), для каждого игрока отдельно. Отношение моба к вам видно в строке Mob Talk над инвентарём и в заголовке окна сделок.

### Житель: торг в окне торговли

У жителя кроме своих сделок есть обычное окно торговли, и уступку в нём тоже можно выторговать голосом:

1. Откройте торговлю, выберите строку, удерживайте **V** и предложите цену. Житель становится собеседником автоматически.
2. Уступка сразу встаёт в окно; в чате появляется `[Mob Talk] Цена в окне торговли: …`. Без этой строки цена не менялась.
3. Цена действует **постоянно** — после покупки не возвращается, переоткрытие окна и перезаход её не сбрасывают. Три уступки за сессию, следующая сессия через 20 игровых минут, от уже сбитой цены вниз до 10% исходного количества.

| Обычные условия | Шаг 1 | Шаг 2 | Шаг 3 (предел) |
|---|---|---|---|
| 22 моркови за 1 изумруд | до 11 | до 5 | до 2 |
| 32 палки за 1 изумруд | до 16 | до 8 | до 4 |
| 20 изумрудов за товар | до 10 | до 5 | до 2 |

Уступка касается первого входного предмета; второй ингредиент и результат не меняются. Отказ (DECLINE) закрывает сессию, но цену сохраняет. Удар по жителю или смена условий сделки снимают уступку.

## Действия мобов

Моб может следовать, убегать, атаковать допустимую цель или отказаться. Решение принимается после ответа; движение и бой выполняются обычными игровыми механизмами.

FOLLOW сохраняется при выборе другого собеседника и после перезапуска мира. Выгрузка сущности приостанавливает его. Удар следовавшего за вами моба отменяет следование.

Мирные мобы могут дать сдачи. Удар игрока вызывает ответную атаку до 20 секунд; повторный удар обновляет это время. Для нападения мирного моба на игрока нужно отношение не выше −40 либо настоящая текущая агрессия; враждебным видам личная ссора для боя не требуется, но перемирие (отношение от +20) запрещает атаку и им. Моб может выбрать атаку и в разговоре, если достаточно разозлён.

Големы, волки и другие боевые виды используют штатную атаку. Животные и жители без своей боевой механики получают временный ближний удар: обычные путь, дистанция, видимость и перезарядка Minecraft; при отсутствии своего атрибута урона — 2 единицы. STOP и выгрузка снимают временное управление. Творческий режим и наблюдатель сохраняют неуязвимость, мирная сложность сохраняет свои правила урона.

Действия зависят от вида и состояния. Рыбы двигаются в воде. Гаст, слизни, магмовый куб и иссушитель поддерживают родную атаку; дракон сохраняет боевые фазы. Взрывы и снаряды настоящие, с соблюдением правил мира. STOP возвращает обычное поведение, включая природную враждебность.

## Игровое меню

Четыре вкладки, каждая — прокручиваемый список с разделами (колесо мыши или полоса справа).

| Вкладка | Возможности |
|---|---|
| Общее | Провайдер ответов (OpenRouter или Venice) и его модель, ключи OpenRouter и Venice (вставка, сохранение, удаление, проверка связи), включение, общий стиль, дерзость, длина ответа, дистанция, запись, таймаут, история и память. |
| Микрофон | Устройство и его проверка с записью, прослушиванием и сравнением моделей; модель, устройство, язык и тонкая настройка Whisper. |
| Виды мобов | Поиск 82 видов и выбор архетипа закреплены сверху; ниже характер вида и архетипа, восстановление профиля, голос, превью и проба через OpenRouter. |
| Выбранный моб | Имя, голос, личность, память, просьбы и STOP, история, события, контекст, сброс истории/памяти/индивидуальности. |

Правки применяются кнопкой **Сохранить**; **Отмена** оставляет прежние настройки. В карточке можно отдельно очистить историю или резюме памяти и создать новую индивидуальность, сохранив голос и отношение. STOP выполняется сразу.

### Сравнение распознавания

Запишите одну фразу удержанием клавиши, отметьте модели и запустите сравнение. Они получают один WAV последовательно. Результаты показывают текст, фактическое устройство, время подготовки и распознавания. Запись можно прослушать и применить понравившуюся модель.

Доступны `small`, `medium`, `large-v2`, `large-v3`, `large-v3-turbo`. По умолчанию `ru`, `beam_size=5`, устройство `auto`. Большие модели требуют больше ресурсов; при нехватке видеопамяти выберите меньшую или CPU. Одновременно загружена одна модель. Запись ограничена 15 секундами и очищается при закрытии проверки.

Старый отдельно запущенный Whisper нужно обновить/перезапустить; автоматически запускаемый помощник копируется из нового JAR. Адрес: `http://127.0.0.1:63919`.

### Голоса и расходы

Каталог: 246 разных основных голосов, по 3 на вид, и отдельные видовые резервы. Разные виды не делят голоса. Первые три особи вида получают разные варианты, далее выбираются наименее занятые.

Подбор основан на публичных карточках ElevenLabs, описаниях и русских языковых метаданных. Публичное превью и успешная генерация Flash v2.5 показываются разными статусами. Массовые платные пробы не выполняются: успешный OpenRouter отмечается после явной проверки или игровой озвучки. При временной сетевой ошибке остаются субтитры.

LLM и TTS расходуют кредиты OpenRouter (LLM — кредиты Venice, если выбран он); локальное распознавание и готовые публичные превью не вызывают платную модель. Java нужен HTTPS-доступ к `openrouter.ai` (и к `api.venice.ai` для Venice); первая загрузка весов Whisper требует HuggingFace.

Если провайдер не принимает строгую JSON-схему вместе с `temperature` (так у Claude Haiku 5.5), мод повторяет запрос без `temperature`, затем пробует совместимый JSON-режим; все игровые проверки остаются в коде. HTTP 429 означает ограничение запросов на стороне OpenRouter/провайдера: можно подождать или выбрать другую текстовую модель в F7.

В торге модель называет итоговую цену, а код проверяет её по разрешённым ценам выбранной строки. Если житель называет цену, которую торг не применил (например, «теперь по 18» без уступки или «восемь», когда в окно ушло бы 19), ответ не озвучивается: модель получает до двух исправлений, и последнее идёт уже без торга, так что вместо ошибки звучит обычная реплика. Просьба о скидке на другой товар превращается в совет выбрать его строку в окне. История и память обновляются после успешной проверки ответа игрой.

Все запросы к OpenRouter идут через одно общее соединение. Пока моб выбран, мод раз в 10–20 секунд простоя шлёт бесплатный запрос информации о ключе, чтобы соединение не закрылось: через некоторые локальные прокси новое соединение стоит несколько секунд.

Проверка подключения использует [информацию о текущем API-ключе](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-api-key); она не запускает LLM или TTS.

### Как устроен код

`core` — чистая Java без Minecraft, покрыта тестами:

| Класс | За что отвечает |
|---|---|
| `ConversationEngine` | Один разговор: промпт → ответ → ранняя озвучка → проверка → фиксация в памяти; биография при первой встрече. |
| `OpenRouterConversationClient` | HTTP к OpenRouter/Venice, стриминг реплики, цикл из двух исправлений, провайдерские особенности. |
| `MobPrompt` + `PromptTexts` | Сборка системного промпта (вид, история, характер, настроение, игрок) и сообщения с данными; все тексты правил — в `PromptTexts`. |
| `ReplySchema` | Строгие JSON-схемы ответа и биографии, сужение enum под снимок. |
| `AnswerValidator` | Проверка ответа модели по снимку: действия, торг жителя, свои сделки, секреты, услуги, «необеспеченные» цены и приёмки, язык. |
| `TradingView` | Типизированное чтение `mobDetails.trading`/`bargaining` — общее для промпта и валидатора. |
| `BiographyWriter` | Запрос и разбор имени, истории, желания, тайны и истории деревни. |
| `ConversationStore` + `WorldMemoryFile` + `ProfileDefaults` | Память мира: профили, отношения, что знает вид, деревни; файл с миграциями и атомарной записью; значения по умолчанию профиля. |
| `Trading`, `Bargaining`, `TradeCatalog`, `FavorItems` | Правила цен, уступок жителя, каталог сделок, пул предметов для услуг. |
| `SpeciesCatalog` | 82 вида, архетипы, голоса, привычки/желание/тайна. |

`client` — Fabric: `MobTalkClient` (клавиши, запись, конвейер разговора, HUD), `MerchantSession` (речь внутри торгового окна), `MobTalkCommands` (`/mobtalk`), `SettingsController` (связь меню F7 с клиентом), `game/*` — integrated server (снимок мира, действия, окно сделок `MobMerchant`, торг жителя `VillagerBargaining`, миксины).

Целевые тесты используют локальные HTTP-фикстуры и подставную модель Whisper. Это не проверка живого микрофона или всех 246 голосов через платный API.
