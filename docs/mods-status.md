# Моды сборки и их статус

Снимок репозитория: **26 октября 2026, `origin/main` @ `9826489b`**. Документ описывает состав, который предписан
скриптами `build-pack.ps1`, `build-server-pack.ps1` и `export-mrpack.ps1`. Живой Prism-инстанс, боевой сервер и их
манифесты в рамках этой сверки не читались, игра и сервер не запускались. Поэтому «в сборке» ниже означает «включён
скриптом сборки», а не «проверен сейчас в игре».

Статусы:

- **клиент + сервер** — входит в клиентский пак и переносится на выделенный сервер;
- **клиент** — входит в клиентский пак и `.mrpack`, на сервер не ставится;
- **сервер** — добавляется только в серверную папку;
- **опционально** — по умолчанию не входит;
- **тестовый** — используется только в одноразовых тестовых инстансах.

Обозначения сторон: **К** — клиентский пак, **С** — выделенный сервер, **M** — экспортируемый `.mrpack`.

Для Fabric API и видео-модов экспорт `.mrpack` ищет исходный файл на Modrinth по SHA-1: при совпадении добавляет ссылку
с SHA-1/SHA-512. Если файл не найден, скрипт помещает его в `overrides/mods`; исключение — CTOV и Lithostitched, которые
внутрь архива не попадают никогда.

## Проверки и известные расхождения документации

- В репозитории есть общий игровой самотест `-Only pack`, сценарии `divine`, `church`, `cages`, `hogweed`, серверные
  самотесты и Pester-тесты упаковки. Их наличие не означает, что они проходили на этом снимке; в рамках составления
  списка запускались только Gradle-тесты и сборка Mob Talk.
- Исторические проверки описаны отдельно: CTOV — в `docs/ctov.md`, видео и нагрузка борщевика — в
  `docs/server-research.md`, серверная интеграция — в `docs/server-plan.md`. Это протоколы прошлых прогонов, не новая
  проверка текущего пака.
- `docs/pack.md` в общей таблице ещё называет Viewer Parrots «оригинальным jar», но раздел «Сервер» того же файла и
  актуальный `PackBuild.psm1` подтверждают сборку из `minecraft-parrot/main`. Актуален второй вариант.
- `docs/server.md` содержит устаревшую оговорку «Mob Talk, пока он клиентский». В актуальном `fabric.mod.json` уже
  `environment: *`, поэтому серверная сборка включает Mob Talk; `-NoMobTalk` пропускает его явно.
- Точный состав реально установленного пака этот документ не подменяет. Для установленного клиента смотреть
  `mob-talk-pack/pack-manifest.txt`, для сервера — `server-manifest.txt`; после смены любого исходного JAR требуется
  новая сборка и сверка манифестов.

## Источники списка

- `scripts/PackBuild.psm1` — собственные репозитории, сторонние JAR и общие правила паков;
- `scripts/server-mods.json` — закреплённые версии и SHA-512;
- `scripts/build-pack.ps1`, `scripts/build-server-pack.ps1`, `scripts/export-mrpack.ps1` — состав клиента, сервера и `.mrpack`;
- `gradle.properties`, `src/main/resources/fabric.mod.json` — версия и окружение Mob Talk;
- `docs/pack.md`, `docs/server.md`, `docs/ctov.md`, `docs/server-research.md`, `docs/server-plan.md` — интеграции и прошлые проверки.
