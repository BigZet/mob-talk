# Что проверить в игре: Mob Talk 0.6.0

19 октября 2026. В main слиты пять треков (D действия, C торг, A память, E место, B отношения)
поверх состояния моба 0.5.0. 216 unit-тестов зелёные, JAR установлен в Prism
(инстанс 1.21.1-fabric-dev). Ни один из пунктов ниже в настоящей игре не прогонялся,
всё проверено только тестами и компиляцией. Отмечайте результат справа.

Полезные команды: `/mobtalk state` (состояние, связи, лизы, торг), карточка моба в F7,
`conversations.json` в папке мира для сводок и фактов.

## Состояние моба (0.5.0, ещё не проверялось)
- [ ] Поговорить дружелюбно 2–3 раза: слово в HUD меняется на «в духе» / «заинтересован».
- [ ] Ударить один раз: «встревожен»; через ~10 минут возвращается к покою.
- [ ] Попытаться торговать с встревоженным: отказ словами, без OFFER.
- [ ] Заинтересованный знакомый моб сам поворачивается к вам в 6 блоках.

## Трек D: действия для друзей
- [ ] Прирученному волку (или голему при отношении от +20) сказать «жди здесь» и отойти: стоит на месте. Дальше 48 блоков в чате «вы ушли слишком далеко». «Пошли» отпускает.
- [ ] Голему при отношении от +60: «охраняй меня», подвести зомби. Нападает в 8 блоках от вас, после боя возвращается.
- [ ] Зомби в перемирии: «не трогай эту корову». Корову не берёт в цель, `/mobtalk state` показывает «Не трогай (Корова)».

## Трек C: торг
- [ ] Смотреть на жителя, удержать V: «скинь морковку до восемнадцати». В чате `[Mob Talk] Сделка в окне торговли: … одна покупка, 10 мин`. Правый клик: внизу новая строка по обещанной цене. Купить один раз, строка исчезает, в памяти «купил по договорённости».
- [ ] Во время торга в строке Mob Talk «торг: склоняется» зелёным; после отказа или просьбы ниже минимума «не уверен» / «против».
- [ ] На глазах жителя открыть сундук в деревенском доме: серая строка «… видел, как вы открыли чужой сундук», отношение −3, возможно «насторожен». Спросить его: припомнит, не нападёт. Свой сундук, поставленный в этой сессии, штрафа не даёт.

## Трек A: память
- [ ] Поговорить 3–4 реплики, навестись на другого моба: через несколько секунд у первого в `conversations.json` появляется `summaries`; в следующем разговоре промпт содержит «Наши прошлые разговоры».
- [ ] Поговорить и помолчать больше трёх минут: сводка появляется без смены цели.
- [ ] Ударить моба, потом поболтать пять раз: в логе фоновая задача `reflection:`, в карточке памяти `[вывод] …`, моб ссылается на вывод.
- [ ] Карточка в F7: память редактируется строка на факт; старый мир загружается, у старых фактов важность 3.

## Трек E: место
- [ ] Яма 3×3 глубиной 4 из бедрока, столкнуть корову, спросить «где ты?»: «на дне ямы 3×3 глубиной 4; стены из бедрока (не прокопать)», «игрок снаружи, выше».
- [ ] Стеклянная клетка: «клетка … всё видно насквозь», «игрок … видно через стекло».
- [ ] Воронка: ступенчатая чаша с водой, внизу дыра или лава: «воронка: стены сужаются книзу, вода тащит вниз, на дне …».
- [ ] Замуровать знакомого моба на глазах: через 2–3 с в памяти событие «Игрок замуровал тебя…», в ответе «это он меня замуровал».
- [ ] Обычный дом: «помещение … дверь … (открыта)», «похоже на: дом (уверенность …)».

## Трек B: отношения между мобами
- [ ] Поговорить с двумя жителями одной деревни, оставить рядом ~20 минут: `/mobtalk state` показывает «семья, друг», они периодически подходят друг к другу.
- [ ] Убить одного на глазах у второго: «скорбит», в ответе упоминает имя погибшего.
- [ ] Если у скорбящего есть друг в 32 блоках, тот один раз подходит и стоит рядом.
- [ ] Волк нападает на знакомую овцу (или зомби на жителя): у жертвы «соперник», при сближении отходит.

## Известные ограничения
- Лизы STAY/GUARD/SPARE не восстанавливаются после перезапуска мира.
- Учёт «своих» блоков для проступков живёт только в памяти сессии.
- Сводка разговора при выходе из мира не делается.
- Два миксина на `BlockItem.place` (трек C и трек E) работают параллельно; объединить при чистке.
- Классификатор места обучен только на синтетических сценах, его вывод подаётся модели как догадка.
- Трек F (Whisper) ещё в работе, трек B часть 2 (слухи, инициатива, решатель Jev) начата.
