# Церковь: кладбище и точки для боссов

Договорённость между тредами «Православная церковь-структура», «Русское кладбище» и «Священные мобы-боссы».
Код церкви — `src/main/java/io/github/divineblock/world/`, а самотест — `ChurchSelfTest`, запускается командой
`scripts/run-selftest.ps1 -Church`.

## Структура

- Структура `divineblock:orthodox_church` входит в набор `divineblock:orthodox_churches`. Размещение
  `divineblock:church_spread` ставит одну церковь на клетку N×N чанков. N — это настройка `churchSpacing`:
  по умолчанию 80, допустимо от 32 до 256, в меню F9 она называется «Редкость». Ближе 4 чанков к деревне
  церковь не встаёт.
- Церкви появляются в биомах из тега `#divineblock:has_structure/orthodox_church`: равнины, луга, леса, тайга,
  снежные равнины, снежная тайга и роща.
- Структура собирается из трёх частей:
  - `divineblock:church` (`ChurchPiece`) — сама церковь, её рисует код, без NBT;
  - кладбище из пула треда кладбища (`PoolStructurePiece`);
  - `divineblock:church_cemetery` (`CemeteryPiece`) — заглушка на случай, если пула нет.
- Вариант `STONE` — белокаменная церковь с 1 или 5 главами и закомарами. Вариант `WOOD` — сруб с восьмериком и
  шатром. В северных биомах чаще встаёт деревянная.

## Поворот и координаты

Церковь описана в своих координатах. +X — восток, там алтарь. +Z — юг, туда уходит кладбище. y = 0 — слой пола,
земля лежит на y = −1. `origin` — пол под западной дверью колокольни.

Сначала генерируется кладбище из пула со случайным поворотом R. Потом церковь разворачивается тем же поворотом R,
чтобы её юг смотрел на кладбище. Получается, что алтарь смотрит строго на восток только при R = NONE.

`ChurchPiece.Frame(origin, rotation).world(x, y, z)` переводит координаты церкви в мировые.

| Что | Координаты церкви |
|---|---|
| Бокс церкви | x −4..36, y −1..44, z −8..8 |
| Алтарь мода (святой престол за царскими вратами) | (31, 1, 0) |
| Сундук `divineblock:chests/orthodox_church` | (32, 1, −3) |
| Печать босса `divineblock:boss_seal` (в полу алтаря) | (32, 0, 2) |
| Центр храма (пол свободен) | (22, 1, 0) |
| Вход на кладбище (джигсо-блок кладбища) | (18, −1, 10) |
| Площадка кладбища 21 × 27 | x 8..28, z 10..36 |

## Кладбище (тред кладбища)

- `ChurchStructure` запускает пул **`divineblock:cemetery/start`** через `StructurePoolBasedGenerator`. Стартовый
  джигсо — **`divineblock:cemetery_entrance`**. Глубина пула — 4, кладбище стартует первым, а берёзы идут на уровень
  ниже. Максимальное расстояние — 80. Проекцию к карте высот церковь не задаёт, её даёт `terrain_matching` в самих
  шаблонах.
- Вход кладбища ставится в точку (18, −1, 10). Шаблон идёт вглубь по +Z, то есть от церкви, по 10 блоков в стороны.
  Свой джигсо в церкви не нужен: церковь стыкуется с входом кладбища кодом.
- Если пула в данных нет (ветка кладбища ещё не слита), на той же площадке рисуется заглушка `CemeteryPiece`.
  В ней еловая ограда, калитка у входа, дорожка и холмики с простыми крестами. Свой пул я не регистрирую и
  не дублирую.

## Боссы (тред боссов)

- **Печать.** Если в реестре есть блок `divineblock:boss_seal`, `ChurchPiece` ставит его в пол алтарной части,
  в точку (32, 0, 2). Блок-энтити получает NBT `{boss:"church", power:3 (STONE) | 2 (WOOD), radius:20, night:false,
  cooldownDays:1}`. Поиск идёт только по id, классы треда боссов не нужны. Если блока нет, на этом месте остаётся пол.
- **Во время игры.** `ChurchSites.at(serverWorld, pos)` возвращает `Optional<Site>` для церкви, в части которой лежит
  `pos`. В `Site` есть:
  - `variant`, `origin`, `rotation`;
  - `altar`, `naveCenter`, `chest`;
  - боксы `church` и `cemetery`;
  - `bossPoints`, в порядке: центр храма, трапезная (10, 1, 1), перед крыльцом (−6, 0, 0) и середина кладбищенской
    аллеи (18, 0, 23).

  Последняя точка стоит на высоте пола церкви, а кладбище повторяет рельеф. Поэтому для неё уточняйте высоту
  по карте высот.
- **Во время генерации.** `ChurchSites.DECORATORS.add((world, chunkBox, site, random) -> { ... })` вызывается для
  каждого чанка, который задевает церковь, в потоке генерации мира. Пишите только внутри `chunkBox`. Мобов спавните
  только в точке, которая лежит в `chunkBox`, иначе моб появится несколько раз.

## Совместимость

- `churches = false` в `config/divineblock.json` или «Церкви в мире: выкл» в F9 отключают новые церкви. Уже стоящие
  остаются, остальной мод работает как раньше.
- Новая редкость действует только на ещё не сгенерированные чанки.
- В старых мирах церкви появляются только в новых чанках.
