# Mob Talk Implementation Plan

> **For agentic workers:** Use scoped parallel subtasks in the current session; keep edits in this independent project.

**Goal:** ПКМ палкой выбирает обычного моба, V записывает вопрос, локальный Whisper + OpenRouter LLM + ElevenLabs дают ответ из позиции моба.

**Architecture:** Отдельный клиентский Fabric JAR, встроенная одиночная игра. Pure Java ядро диалогов и JSON-памяти, клиентский игровой адаптер, локальный Python Whisper worker.

**Tech Stack:** Java 21, Minecraft 1.21.1, Fabric Loader 0.19.5, Fabric API 0.116.17+1.21.1, faster-whisper, OpenRouter.

**Spec:** ../../design.md

## Global Constraints
- Самостоятельный проект/JAR без зависимости от Viewer Parrots.
- Секреты только в локальном окружении/отдельном файле или DPAPI; не печатать их.
- 15 секунд записи; 45 слов ответа; 6 последних обменов; краткая память 1200 символов.
- Смена цели/мира отменяет устаревший ответ, обычное поведение моба сохраняется.

## Interfaces
- `core.MobSnapshot`: UUID id, String type/name/dimension/biome/timeOfDay/weather/heldItem, float health/maxHealth, double distance, List<String> nearby/recentEvents.
- `core.ConversationEngine(MobTalkConfig config, Path worldDirectory, Path configDirectory)`; `Reply converse(MobSnapshot snapshot, String userText)`; `void close()`.
- `core.ConversationEngine.Reply(String recognizedText, String responseText, String speakerName, String voiceId, byte[] pcm)`.
- `core.WhisperClient(MobTalkConfig config)`; `String transcribe(byte[] wav)`.
- Python: GET `/health`, POST `/transcribe` with raw WAV body; returns `{text:...}`; loopback only.

## Verification Results
- Pure Java: 12 focused core tests and 4 microphone WAV boundary tests passed; Python helper: 14 focused tests passed.
- One real synthetic cow LLM/TTS conversation returned 249600 bytes of mono PCM16 at 24 kHz (5.2 seconds), with isolated world memory.
- Real local Whisper HTTP transcription matched the Russian synthetic recording on CUDA. PyAV 19 rejected `metadata_errors`; pinning official PyAV 16.1.0 repaired that boundary.
- Separate Minecraft 1.21.1 world: stick selection, `/mobtalk say`, factual reply about grass/player/stick, saved UUID profile, and `/mobtalk mic list` worked. No Viewer Parrots dependency was loaded.
- Live microphone speech through V has not been recorded by the agent; the open test world is ready for the user to try it.

## Review Focus
- Silence must not create a fabricated question or paid LLM call.
- Target/world changes must discard stale playback; dead/unloaded mobs cannot speak.
- Reopening a world keeps each UUID's identity and bounded memory.
- Missing model/key/helper/network produces actionable short feedback instead of freezing Minecraft.
- Whisper helper uses loopback and finite audio bounds; key never enters logs or prompts.
