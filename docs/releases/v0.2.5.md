# Mob Talk 0.2.5

Fabric-мод для одиночной Minecraft 1.21.1: выберите моба палкой и поговорите
с ним голосом. Локальный Whisper распознаёт речь, OpenRouter LLM отвечает с учётом
личности и мира, ElevenLabs Eleven Flash v2.5 озвучивает ответ из позиции моба.

## Что внутри

- Личности, память об отношении игрока и родные действия мобов: следовать,
  убегать, атаковать, отказаться.
- Голосовой торг с жителями прямо в окне торговли.
- Игровое меню F7: микрофон, модели Whisper, LLM и голоса.

## Установка

Нужны **Minecraft Java 1.21.1**, **Java 21**, **Fabric Loader 0.19.5**,
**Fabric API 0.116.17+1.21.1**, **Python 3.12** и **PowerShell 7**.

- `mobtalk-0.2.5.jar` — готовый мод.
- `mobtalk-0.2.5-windows.zip` — мод, скрипты установки Whisper и лицензии.

Пошаговая установка: [README](https://github.com/BigZet/mob-talk#установка-с-нуля).
Ключ OpenRouter хранится локально и не входит в JAR.

Mob Talk не зависит от [Viewer Parrots](https://github.com/BigZet/minecraft-parrot).
