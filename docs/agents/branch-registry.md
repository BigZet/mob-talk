# Реестр веток и ворктри с уникальной работой

Создан 3 ноября 2026 по итогам полной сверки веток агентом GLM (opencode); вечером 3 ноября по решению
Дмитрия выполнена чистка, затем — консолидация: бандиты и горожанки влиты в `main` (PR #10, PR #9),
милиция собрана в одну ветку. Решение Дмитрия действует до отмены:

1. Уникальная работа **хранится в носителях из раздела «Хранить»** — не удалять их и не терять.
2. Фичи **сливать в `main` по мере готовности**; состояние фичи определяет, берём ли её в сборку (пак):
   фичи, ждущие городов, в `main` есть, но **в пак не включаются, пока не доработаны города**
   (носитель городов — `bigzet/city`).
3. При слиянии **явно указывать зависимости** модов (раздел «Зависимости» в `docs/mods-status.md`).
4. Ветка с работой, которая уже влита в носитель или в `main`, **удаляется**.

Сверка делалась по деревьям файлов (two-dot diff), не по patch-id: squash-слияния ломают сравнение коммитов.

## Правило сборки

Пак собирается из checkout `main`, но состав определяется **состоянием фичи**: спящие фичи (бандиты,
горожанки — ждут городов) в пак не включать, пока не доработаны и не влиты города; милиция вольётся в
`main` сразу за городами и попадёт в пак вместе с ними. До тех пор в `build-pack.ps1` /
`build-server-pack.ps1` их не включать. Сторонние моды пака — `docs/mods-status.md`.
Целевое использование (Дмитрий, 3 ноября): серверный мод для игры с друзьями — сервер на ПК Дмитрия или
внешний; одиночная игра поддерживается тем же JAR.
