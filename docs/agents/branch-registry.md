## Правило сборки

Пак собирается из checkout `main`: фича попадает в пак только после слияния её ветки в `main`,
а ветки кластера городов сливаем после доработки городов. До тех пор в `build-pack.ps1` /
`build-server-pack.ps1` их не включать. Сторонние моды пака — см. `docs/mods-status.md` (список верен,
подтверждено Дмитрием 3 ноября 2026).
