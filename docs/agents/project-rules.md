## Лицензии

- Проект под GPL-3.0. В наши JAR попадает только код под GPL, LGPL или MIT, с файлами лицензий в `third_party/`
  и записью в THIRD_PARTY_NOTICES.md.
- Моды под CC BY-NC-ND или «все права защищены» — только отдельными jar в паке, никакого их кода у нас.
  Механики из закрытых модов — только «чистой комнатой» (по описанию, без чтения их кода).
- Материалы, которые приносит сам Дмитрий (картинки, звуки, тексты), он проверяет сам: не исследуйте их лицензии.

- Мир `stream 1` и основной инстанс Prism `1.21.1-fabric-dev` (`%APPDATA%\PrismLauncher\instances\1.21.1-fabric-dev`):
  ничего не ставить и не менять без явного согласия Дмитрия.
- Боевой сервер (Timeweb, mc.amlplay.ru): ничего не деплоить и не перезапускать без просьбы Дмитрия.

## Самотесты и проверка

- Агент сам гоняет самотесты своей ветки, но **без TTS** (это стоит денег); окно самотеста не берёт фокус
  (selftest-guard в `tools/selftest-guard`).
- На ПК не больше 6 игр Minecraft одновременно, считая игры Дмитрия; самотесты идут в одноразовых копиях
  инстанса (docs/parallel-selftest.md). Порт 25566 занят интеграционным сервером, выбирайте другие порты.
- Порядок для визуальных вещей: быстро запустить игру, снять скриншоты, исправлять, пока не исчезнут явные
  артефакты; только потом показывать Дмитрию и гонять полный самотест.
- Показывая результат, прикладывайте скриншоты файлами или давайте полные реальные пути (без `%VARS%`).
- Религиозные детали (православная церковь, иконы, облачения) должны быть верными.

## Визуальный стиль (Дмитрий, 24 октября)

- Интерфейс, предметы, рамки — в пиксель-арте Minecraft, но с богатой детализацией.
- Эффекты (частицы, лучи, свечение) — плавные, пышные, искрящиеся, через библиотеку Fx; не пиксельные.
- Для божественного — дух православного храма. Без виньеток и затемнения экрана. Не перегружать:
  маленькие информационные карточки.
- Меню всех модов в стиле Parrot Cages со сворачиваемыми группами, как в F7.

## Решения по игре и серверу

- LLM оплачивает админ сервера, лимитов трат по умолчанию нет. Основной провайдер LLM и TTS — OpenRouter.
- Отношения и квесты у каждого игрока свои, слухи общие и с реальными никами; брак только с одним игроком.
- Наказания бога бьют всех, бан и благословения — только того, кто просил. Роли: admin, streamer, player;
  белый список по нику.
- После переезда на сервер все исправления делаются в серверной версии (она же одиночная).
- Метки карты (смерть и свои) обязаны появляться на карте веб-админки и совпадать с картой в игре.

## Облако (Linux-контейнер)

- Java 21 есть, сеть пускает Fabric/Mojang/Gradle. repo.maven.apache.org через прокси сбоит (404/429), поэтому
  нужен init-скрипт `~/.gradle/init.d/central-mirror.gradle`, который переписывает адреса Maven Central на
  `https://maven-central.storage-download.googleapis.com/maven2/` (и для `pluginManagement`, и для проектов).
  После сбоя удалите `~/.gradle/caches/modules-2/metadata-*`. Запуск: `./gradlew build --no-daemon --max-workers=2`.
- Клиент Minecraft можно запустить под `xvfb-run` (Mesa) ради скриншотов; Prism-инстансы — только на ПК.
