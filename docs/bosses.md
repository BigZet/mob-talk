# Святые стражи: боссы Божественного блока

Четырнадцать враждебных боссов в тёмном православно-библейском стиле: у каждого своя модель и текстура, полоса здоровья, фазы,
обычные атаки и ульта, свой эффект-недуг и своя реликвия. Код — `src/main/java/io/github/divineblock/boss/`, клиент —
`src/client/java/io/github/divineblock/client/boss/`, модели и текстуры рисует код — `scripts/bosses/*.py` (оригинальные,
GPL-3.0).

## Честный бой

- Каждый удар предупреждён: частицы и звук не меньше чем за ~0,75 с, ульта — титром за 3 с (`SacredBoss.castUltimate`).
- Один удар снимает не больше 45 % максимального здоровья игрока (`SacredBoss.hurt`), так что с одного удара не убить.
- Сила босса 1..5 (здоровье и урон) и общая «Сила боссов» 50–300 % из настроек.
- Блоки (стекло, огни, ров, башня, бассейн) ломаются только при «Ломать блоки» в F9 и правиле `mobGriefing`; иначе у той же
  механики есть безопасный вариант. Временные постройки боссов (башня Нимрода, бассейн Левиафана) убираются.
- Боссы не пользуются LLM и TTS: сбой сети бою не мешает. Отладочные строки — только с «Отладкой» в F9.

## Где появляются

- **Церковь**: под полом алтаря лежит `divineblock:boss_seal` (`{boss:"church"}`), когда игрок подходит — встаёт страж
  церкви (Схимник, Серафим, Безликий лик или Херувим), снова — через сутки после гибели.
- **Кладбище**: в начальных шаблонах `cemetery_1..3` у конца тропы, в (10, 0, 24), — печать `{boss:"cemetery", night:1,
  cooldownDays:1, radius:14}`, ночью встаёт Звонарь или Плакальщица.
- **Кары бога**: группа «святые стражи» (KS, между К4 и К5) — один из 11 боссов, без повторов подряд; Архангел, Всадники и
  Зверь — в «конце света» (К5). Деяния `Miracle.BOSS_*`.

## Бог с булавой (кара `god_mace`)

Не босс, а кара высшей группы (К5, `Miracle.GOD_MACE`): сам бог — фигура в ~33 блока, по пояс в грозовой гряде облаков в
25–40 блоках перед игроком, склоняется к его камере, светится сам (виден днём, в грозу и ночью). Небо темнеет, гром, песнопение,
одна реплика бога (без LLM); 20–60 с он бьёт булавой: удар сверху (круг на земле, ударная волна — перепрыгнуть), размашистый
удар полосой и брошенная молния, каждый с предупреждением ≥1,2 с, урон с тем же потолком 45 %; воронки и огонь — только при
«Ломать блоки» и вне защиты (`Protection`). Потом уходит в облака, небо светлеет. Неуязвим, не сохраняется.

```java
GodWrath handle = DivineBosses.spawnGodAvatar(world, player, power, durationTicks);  // null там, где нет неба (Ад)
handle.dismiss();                         // уйти раньше
DivineBosses.dismissGodAvatar(player);    // например, при искреннем покаянии
```

В F9 → «Боссы…» переключатель «Бог с булавой»: выключен — вместо фигуры гроза с ударными кольцами. Тест:
`-Ddivineblock.bosstest=true -Ddivineblock.bosstest.god=true`, команда `/divineblock act god_mace 4`.

## API для другого кода

```java
DivineBosses.spawn("black_schemnik", world, pos, 3);                      // по id, сила 1..5
DivineBosses.spawn(BossKind.CHERUB, world, pos, 3, player);               // и сразу на цель
DivineBosses.spawnFor(BossKind.Place.CEMETERY, world, pos, 2, random);    // случайный босс места
BossSealBlockEntity.configure(world, pos, "cemetery", 2, true, 1);        // настроить печать из кода
```

Места: `CHURCH, CEMETERY, GOD, FINAL, WATER, WILD, NIGHT`. Выключенный в настройках босс приходит заменой — ванильным мобом с
его именем, усиленным здоровьем и силой. NBT печати: `boss` (id или место `church`/`cemetery`/`god`/`final`), `power`,
`radius`, `night`, `cooldownDays` (−1 — один раз).

## Настройки (F9 → «Боссы…»)

Каждый босс вкл./выкл. (выключенный — ванильная замена), «Сила боссов» 50–300 %, «Ломать блоки». Тряска камеры от недугов
слушается общего «Тряска камеры».

## Проверка

- `/divineblock boss <id> [сила]`, `/divineblock boss ult` (ульта ближайшего), `/divineblock boss clear`.
- Тест в игре: `-Ddivineblock.bosstest=true` (все боссы: атака, ульта, недуг, фаза, реликвия; замена, печать, команда),
  `...bosstest.only=<id,id>` — выборочно, `...bosstest.showcase=true` — витрина: босс неподвижно рядом со стойкой ростом с
  игрока, восемь ракурсов (спереди, сбоку, сзади, снизу с высоты глаз, голова, руки, верх, над головой), `python
  scripts/bosses/sheet.py <id>` — лист для ревью.
- Модели: `python scripts/bosses/<id>.py` пересобирает `<Name>ModelData.java` и текстуры (4 пикселя на единицу, объёмный
  свет, прозрачные края тонких плоскостей).
