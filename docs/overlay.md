# Оверлей для OBS

Страница только для чтения, которую стример добавляет в OBS как источник «Браузер». На ней видны
субтитры жителей и бога, настроение бога и последний приговор, милость игроков, текущие кары,
благословения, боссы и события с таймером.

## Как включить

1. F7 → «Общие» → «Оверлей для стрима» → «Оверлей включён». Мод поднимает страницу на
   `http://127.0.0.1:8790/overlay/` (порт меняется там же).
2. «Скопировать адрес» → в OBS: Источник → Браузер → URL, 1920×1080, «Обновлять браузер при показе сцены» не нужно.
3. «Тестовые данные» показывают 30 секунд выдуманного состояния, чтобы настроить сцену без игры.

Отдельные виджеты: `/overlay/subtitles`, `/overlay/god`, `/overlay/mercy`, `/overlay/now`.
Параметры адреса: `?scale=120`, `?theme=cages|parchment|minimal`, `?calm=1` (без анимаций).

## Кто получает данные

Страницу отдаёт клиент стримера, сервер только присылает пакет `overlay_state` раз в 2 секунды и
только при изменениях. Права: в админке F9 / веб-админке «Оверлей для стрима» (`streamOverlay`,
`streamOverlayAudience` = `streamer` или `all`). По умолчанию оверлей получают стример и админ, в
одиночной игре хозяин мира. Игрок, выключивший «Показывать меня на оверлее», не попадает в список
милости, а приговоры и кары по нему идут без имени.

Субтитры: только то, что слышит сам стример (те же пакеты речи, что и в игре), текст появляется,
когда начинает звучать голос. Реплики бога приходят от божественного блока только слышавшим их.

## Божественный блок

Сервер спрашивает `divineblock` через точку входа `mobtalk-admin` операцией `{"op":"overlay"}`.
Старый божественный блок без этой операции тоже работает: состояние собирается из `souls`, `active`
и `prayers` (настроение бога тогда оценивается по последним молитвам, милость показана словом).

## Команды

- `/mobtalk admin overlay say <минуты> <текст>` — объявление на оверлее всех стримеров (1–120 минут).
- `/mobtalk admin overlay clear` — убрать объявление.

То же в веб-админке: действия «overlay-banner» и «overlay-clear».

## Безопасность

Сервер слушает только 127.0.0.1, отвечает 403 на чужой Host (защита от DNS rebinding), только GET,
CSP `default-src 'self'`, весь текст вставляется как текст, не HTML.
