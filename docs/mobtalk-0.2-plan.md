# Mob Talk 0.2 — implementation brief

User-approved specification: the detailed plan in the conversation, 15 October 2026. This file records the shared contracts and all 82 personality briefs for parallel implementation.

## Constraints and defaults

Independent client Fabric mod, Minecraft1.21.1, singleplayer integrated server. Keep secrets out of JSON/Git/logs/JAR. Mic hold-only max15s. Network/STT/mic/disk off game threads. Reuse storage and HTTP/audio services. No multiplayer/server infrastructure or audit loops. Preserve existing dedicated codex/mob-talk checkout; sibling minecraft-parrot is untouched.

History24 exchanges sent, configurable1..64;100 on disk; memory4000chars. Per-UUID stable species archetype +3-voice least-used assignment, two individual traits, relationships, events. Species types have disjoint pools:246 unique actual public library IDs, metadata/preview checks separate from live OpenRouter v4 Turbo success. Real probes only requested or first game use. Default beam5, ru, models small/medium/large-v2/large-v3/large-v3-turbo; recommend large-v3. One recording comparison sequentially, one GPU model loaded, download progress/cancel.

Fresh authoritative snapshot afterSTT: two hands/count/name/enchants, visible equipment/status, mob specifics/owner/profession/panda/anger, time/weather/light/biome/dimension,16observed entities within24blocks and features within8loadedblocks. Warden filters visual information. Capture immutable DTO, game objects stay server-side.

Relation -100..100: neutral0, hostile-80 cappednegative, ownerpositive. Hit<=-80 then-20; apology+5/60s, verifiedhelp+20/30s, insult-10/60s; no time forgiveness. Attribute actual player/projectile damage beforeselection; cancel stale reply if damage revision changes.

Actions NONE/FOLLOW/FLEE/ATTACK/STOP chosen once per reply and revalidated server-side. FOLLOW3–5blocks persistent untilcancel/change, independent of selecteddialog and conversationdistance; unload pauses. FLEE16m/20s, native combat only. Actual creeper/ghast destruction respects gamerules. Goal/Bird/Swim and separate Brain adapters. Ghast/slime/magma/witherattackonly; squid/bat/giant/dragon no movement commands. STOP removes override and restores vanilla hostility. Player and observedaliases only, no arbitrarycommands/NBT.

Five menu sections:GeneralLLM,MicrophoneSTT,Characters,Voices,SelectedMob. Immutable draftsave/cancel/reset; profile/3variant editor, previews/checks, relation/memory/context/actioncard, askactions viaLLM, directSTOP/allfollowersSTOP.
