# Кладбище

Русское православное сельское кладбище: блоки для игрока и структура, которую церковь пристраивает к себе.

## Блоки

Все в творческой вкладке «Божественный блок» (`divineblock:main`, там же алтарь). Ставятся лицом к игроку.

| id | Блок | Рецепт |
|---|---|---|
| `wooden_cross` | Деревянный восьмиконечный крест, светлое лакированное дерево (2 блока, с табличкой) | ` S ` / `PSP` / ` S `: палки S, любые доски P |
| `roofed_cross` | Крест с кровелькой (голубец) | деревянный крест + любая деревянная плита |
| `old_cross` | Старый покосившийся крест, серое дерево с лишайником | деревянный крест + лоза |
| `iron_cross` | Кованый крест: чёрный, с золотыми ромбами и кольцом, на постаменте | ` N ` / `IDI` / ` I `: золотой самородок N, железо I, чёрный краситель D |
| `star_obelisk` | Пирамидка с красной звездой и фото (2 блока) | ` R ` / ` I ` / `IGI`: красный краситель R, железо I, бумага G |
| `granite_stele` | Чёрный гранитный памятник с закруглённым верхом, фото, строками и гравированной свечой | `BPB` / ` B ` / `SSS`: полированный чернит B, бумага P, каменная плита S |
| `marble_stone` | Мраморный камень с крестиком | ` C ` / `CCC`: кальцит → 2 |
| `grave_mound` | Могильный холмик (могила — 2 холмика подряд); костная мука — зарастает травой, лопата или мотыга — снова чистый | `DDD`: земля → 2 |
| `black_grave_fence`, `blue_grave_fence` | Оградка: низкая, тонкие прутья, шарики на столбиках (соединяется как забор) | `NDN` / `NIN`: железные самородки N, слиток I, чёрный или голубой краситель D → 6 |
| `black_grave_gate`, `blue_grave_gate` | Калитка оградки | `IDI` / `INI` |
| `grave_bench` | Лавочка | `SSS` / `N N`: деревянные плиты S, железо N |
| `grave_table` | Столик на одной ножке | `SSS` / ` N ` / ` N ` |
| `funeral_wreath` | Траурный венок с лентами | ` F ` / `FLF` / ` F `: любые маленькие цветы F, еловая листва L → 2 |
| `artificial_flowers` | Искусственные цветы в вазочке | бумага + красный и зелёный красители + палка → 2 |
| `granite_cross` | Гранитный крест с трилистниками на постаменте (2 блока) | ` B ` / `BBB` / ` S `: полированный чернит B, плита из него S |
| `white_metal_cross` | Белый металлический крестик (2 блока) | ` N ` / `NWN` / ` N `: железные самородки, белый краситель |
| `stone_trunk_cross` | Старый каменный крест «дерево» со срезанными сучьями на высоком постаменте | ` C ` / `CCC` / `SSS`: замшелый булыжник, каменные кирпичи |
| `gothic_marble_stone` | Старое мраморное надгробие со стрельчатым верхом | мраморный камень + кальцит |
| `grave_slab` | Гранитная плита на могилу (2 подряд) | `BBB`: плиты из полированного чернита → 2 |
| `rusty_grave_fence`, `rusty_grave_gate` | Ржавая оградка и калитка | как чёрные, с коричневым красителем |
| `sector_sign` | Синяя табличка участка «1 1» на столбике | ` D ` / ` P ` / ` S `: синий краситель, бумага, палка |
| `cemetery_bin` | Синий мусорный бак | `N N` / `NDN` / `NNN`: железные самородки, синий краситель |

Модели и текстуры свои (рисует `scripts/cemetery/assets.py`, без копирования ресурсов игры). Высокие кресты и пирамидка
занимают два блока: модель висит на нижней половине, верхняя держит место и хитбокс; ломается целиком, предмет падает один.

## Структура для церкви

Плотное русское кладбище: одна главная тропа шириной 3 (посередине утоптанная земля, по краям подзол, трава), вдоль неё
вплотную оградки; за первым рядом — второй, оградки общие, к задним участкам ведут узкие лазы. В каждом куске 24 участка
в оградках с калитками; есть современные части (чёрный гранит, плиты на могилах, чёрные оградки, кресты с кровелькой) и
старые заросшие (ржавые оградки, мрамор, каменные кресты, папоротник, больше деревьев). Деревья редкие, 0–3 на кусок:
дуб и берёза (чаще высокие), в тайге и холодных биомах — ель, сосна, берёза (`divineblock:cemetery_tree`).

| Кусок | Пул | Размер x × z | Вход (джигсо, смотрит на север) | Выход |
|---|---|---|---|---|
| начало, 3 варианта | `divineblock:cemetery/start` | 21 × 27 | (10, 0, 0) `divineblock:cemetery_entrance` | (10, 0, 26) → `cemetery/rows` |
| ряды, 3 варианта | `divineblock:cemetery/rows` | 21 × 24 | (10, 0, 0) `divineblock:cemetery_rows` | (10, 0, 23) → `cemetery/end` |
| край, 2 варианта | `divineblock:cemetery/end` | 21 × 7 | (10, 0, 0) `divineblock:cemetery_end` | — |

- Всё кладбище: **21 × 58** блоков, 48 участков, растёт по тропе прочь от церкви (+z в рамке шаблона); 10 блоков в
  стороны от оси входного джигсо.
- Глубина цепочки от элемента церкви с джигсо: начало +1, ряды +2, край +3, деревья края +4. `size` структуры церкви
  должен быть не меньше (глубина этого элемента) + 4; радиус: расстояние от центра церкви до входа + 58.
- Все куски `terrain_matching`, процессор `divineblock:cemetery`. y 0 — слой земли (тропы заменяют верхний блок),
  остальное стоит на y 1.
- Как пристроить: в шаблоне церкви джигсо на краю, смотрит наружу: `pool` = `divineblock:cemetery/start`,
  `target` = `divineblock:cemetery_entrance`.

## Проверка

- `/divineblock cemetery` — поставить кладбище там, где стоит игрок (вне биомов `divineblock:has_structure/orthodox_church`
  — с предупреждением). То же: `/place structure divineblock:cemetery` (сама в мире не появляется: нет structure_set).
- `/place template divineblock:cemetery/cemetery_1` — сырой шаблон без подгонки по рельефу и без берёз.
- `scripts/run-cemetery-test.ps1` — автотест на экземпляре Prism `divine-block-test`: все блоки на лужайке, участок вручную,
  шаблон и структура на природе, снимки `cemetery-*.png` и отчёт в `%LOCALAPPDATA%\DivineBlock\cemeterytest`.
- Шаблоны и пулы пересобирает `python scripts/cemetery/structures.py` (раскладка из сида, свой читатель/писатель NBT).
