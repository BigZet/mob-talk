# Как зайти на сервер Mob Talk (для друзей)

Проще всего — установщик: архив `mob-talk-installer-….zip` из релиза, внутри `install-windows.bat` и
`install-macos.command`, он сам поставит Prism и пак с сервером в списке (`docs/install-players.md`). Вручную:

1. Поставьте [Prism Launcher](https://prismlauncher.org/download/) и войдите в свой аккаунт Minecraft
   (Аккаунты → Добавить Microsoft).
2. Возьмите у Дмитрия файл `mob-talk-pack-….mrpack`. В Prism: **Добавить экземпляр → Импорт** → выберите файл → ОК.
   Prism сам скачает CTOV, Fabric API и видео-моды, наши моды уже внутри файла.
3. Запустите экземпляр, **Сетевая игра → Добавить сервер**, адрес даст Дмитрий. Ваш ник должен быть в allowlist сервера.
4. Микрофон: при первом запуске разрешите Java доступ к микрофону (Windows: Параметры → Конфиденциальность → Микрофон).
   Зажмите **V**, глядя на жителя или моба, говорите, отпустите — он ответит голосом.
5. **F7** — ваши настройки: микрофон и громкость, как распознавать речь (на своём компьютере, если есть видеокарта, или
   через сервер — ставить ничего не нужно), как вас называть. Серверные настройки там видны, но меняет их только админ.

Ещё клавиши: **G** подарить предмет из руки, **B** сделки, **R** помолиться у Божественного блока, **Caps Lock** голосовой чат
с игроками (окно настроек **Y**), **J** карта. Платить ни за что не нужно:
нейросети оплачивает сервер.
