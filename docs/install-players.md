# Установщик для новых игроков (Windows и macOS)

Один архив `mob-talk-installer-<версия>.zip` из релиза на GitHub: внутри установщики для Windows и macOS, памятка
`README.txt` и сам пак `.mrpack`. Игрок распаковывает архив и запускает установщик своей системы. Тот ставит
Prism Launcher 11.1.1 (если Prism ещё нет) и открывает импорт пака; сервер уже в списке «Сетевая игра».
Игроку остаётся нажать OK, войти аккаунтом Microsoft и запустить сборку.

## Для игрока

**Windows 10/11.** Распаковать архив, дважды щёлкнуть `install-windows.bat`. На «Система Windows защитила ваш компьютер»
нажать «Подробнее» → «Выполнить в любом случае». Права администратора не нужны: Prism ставится портативно в
`%LOCALAPPDATA%\MobTalk\PrismLauncher`, появляются ярлыки «Prism Launcher (Mob Talk)» на рабочем столе и в «Пуске».
Если Prism уже установлен обычным установщиком, используется он.

**macOS 12+.** Дважды щёлкнуть архив в Загрузках, затем `install-macos.command`. Если macOS не даёт открыть файл
(«не удалось проверить разработчика»): Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»,
или в Терминале `bash ~/Downloads/mob-talk-installer/install-macos.command`. Prism ставится в `~/Applications`
без пароля администратора; уже установленный в `/Applications` или `~/Applications` используется как есть.

**Дальше в Prism.** При первом запуске Prism покажет свою настройку (язык, Java) — «Далее» до конца, после неё
откроется окно импорта пака: OK. Аккаунты → Управление аккаунтами → Добавить Microsoft. Сборка Mob Talk → Запустить
(Java 21 Prism предложит скачать сам). Сетевая игра → сервер Mob Talk. Ник игрока должен быть в allowlist сервера.

Клавиши сборки: V — говорить с мобом, F7 — настройки, G — подарок, B — сделки, R — молитва; голосовой чат с игроками —
Caps Lock (окно настроек Y, группы U); карта JourneyMap — J, метка — K.

## Для админа: собрать архив

```powershell
scripts\build-pack.ps1                                    # пак с новыми модами
scripts\build-installer.ps1 -ServerAddress mc.example.ru  # mrpack с сервером в списке + zip установщика в ...\dist
```

К релизу прикладываются оба файла: `mob-talk-installer-….zip` (для новых игроков) и `mob-talk-pack-….mrpack` (для тех,
у кого Prism уже есть). Если игрок запустил установщик без `.mrpack` рядом, он сам скачает `.mrpack` из последнего
релиза `BigZet/mob-talk` (с проверкой SHA-256 из релиза).

Что внутри: `installer\install-windows.ps1` (+ `.bat` для двойного щелчка), `installer\install-macos.command`,
`installer\README.txt`. Prism качается с официального GitHub PrismLauncher по закреплённой версии и сверяется с SHA-256
этого релиза; чтобы обновить Prism, поменяйте версию и суммы в обоих скриптах. Скрипт macOS хранится с LF
(`installer\.gitattributes`), `scripts\zip_installer.py` ставит ему права 755 в архиве.

## Что проверено

- Windows: установщик из собранного архива в песочнице (`-PrismDir <папка> -NoShortcuts`): скачал Prism 11.1.1, сверил
  SHA-256, распаковал, включил портативный режим и запустил Prism с `--import` пака. Prism открыл первичную настройку;
  клики по окнам (настройка, OK в импорте) не прогонялись.
- macOS: только `bash -n` и чтение глазами, на Mac не запускался.
